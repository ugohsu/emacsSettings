# ugr-framenames

R のデータフレーム (またはリスト) の列名を、Emacs のミニバッファで補完しながら選んで、
R のコードに挿入する elisp。「非連結子会社関連会社.受取手形.売掛金」のような長くて
間違えやすい列名を打ち込むときに使う。

| コマンド | 動作 |
|---|---|
| `M-x ugr-framenames` | データフレームの名前を聞き、R からその列名を読み込む |
| `C-c i` (`M-x ugr-insert`) | 読み込んだ列名から 1 つ選び、`"列名"` とダブルクォート付きで挿入する |

## 前提

- ESS で R を起動していて、今のバッファが R のプロセスにつながっていること
  (R のスクリプトのバッファか、R のコンソール `*R*`)。
- `init.el` で `ugr-framenames` を autoload している (`ugr-insert` は `ugr-framenames` を
  一度実行すると使えるようになる)。

## 使い方

1. `M-x ugr-framenames` を実行し、`data.frame or list: ` にデータフレームの名前 (例: `tmp`) を入れる。
   R で `writeLines(names(tmp))` を実行して、列名を読み込む。
   - 初めて実行したときに、`C-c i` を `ugr-insert` に割り当てる (`ess-mode-map`。R のスクリプトの
     バッファで効く)。R のコンソールには割り当てないので、そこでは `M-x ugr-insert` を使う。
   - 読み込んだ列名は 1 組だけ持つ。別のデータフレームに移るときや、列を変えたときは、もう一度実行する。
2. 列名を入れたい位置で `C-c i` を押し、`frame names: ` で列名を選んで `RET` を押す。
   - ミニバッファでは SKK がかなモードで有効になる (日本語の列名を打てるように)。
     英字の列名は `l` でアスキーモードにしてから打つ。
   - vertico・orderless が効くので、`非 売掛` のように列名の一部をスペースで区切って打てば絞り込める。
     大文字と小文字は区別しない。
   - 読み込んだ列名にないものは選べない。

## 使用例

`tmp` というデータフレームに、日経の貸借対照表のデータが入っているとする。列が 214 もあり、
列名は長い日本語になっている。

```r
> str(tmp)
'data.frame':	78527 obs. of  214 variables:
 $ 株式コード                          : int  1301 ...
 $ 日経会社コード                      : int  1 1 ...
 $ 日経業種集計値コード                : logi  NA ...
 $ 決算期                              : int  198410 ...
 ...
```

ここから分析に使う列だけを取り出して、列名を英字に付け替える。`M-x ugr-framenames` で `tmp` を
読み込んでおき、`tmp[c(` まで打ったら `C-c i` で列名を 1 つずつ挿入していく (間は `, ` を打つ)。

```r
bs <- tmp[c("日経会社コード", "決算期", "決算月数", "資産合計", "負債合計",
            "繰延税金資産", "非連結子会社関連会社.受取手形.売掛金")]
colnames(bs) <- c("FIRM", "YEAR", "NMONTH", "ASSET", "LIABILITY", "DTA", "ETC")
```

取り出した列は、指定した順に並ぶ。dplyr を使うなら、取り出しと付け替えを 1 度にできる。

```r
bs <- dplyr::select(tmp, FIRM = "日経会社コード", YEAR = "決算期", NMONTH = "決算月数",
                    ASSET = "資産合計", LIABILITY = "負債合計", DTA = "繰延税金資産",
                    ETC = "非連結子会社関連会社.受取手形.売掛金")
```

## 経緯

- 以前は、R 側の `frame.select(データ, "列名", ...)` という関数 (列を取り出して指定した順に並べる)
  と組にして使っていた。`frame.select` はこのリポジトリには入っていない。上の `tmp[c(...)]` か
  `dplyr::select` で同じことができる。

  UTF-8 にして書き直したもの。
