# dired tutor

vimtutor のように、手を動かしながら dired の操作を覚えるための課題集。
キーはこのリポジトリの `init.el` (evil + evil-collection と自分の設定) を前提にしている。
素の Emacs のキーとは違うところがある (例: 行を隠すのは `k` ではなく `s`)。

## 始め方

```sh
bash emacsSettings/tutor/dired/setup.sh   # emacsSettings はこのリポジトリの場所
cd ~/dired-tutor
```

`C-x e` (bash の割り当て。`emacs -nw .` を実行する) で dired が開く。

- 練習用のディレクトリは `~/dired-tutor` にできる。`bash setup.sh 作成先` で場所を変えられる。
- 壊しても `setup.sh` をもう一度実行すれば、まっさらな状態に作り直せる。
  作り直すときに消すのは、目印のファイル `.dired-tutor` があるディレクトリだけ。
- 各レッスンは対応するディレクトリ (`1-move` など) の中でやる。順番どおりでなくてもよい。
- `x` などで確認を求められたら `y` で答える (`yes-or-no-p` を `y-or-n-p` にしているため)。
- キーの割り当ては `SPC B` (embark-bindings) か `<f1> k キー` で調べる。
  normal state では `C-h` を左移動にしているので、`C-h k` ではヘルプが開かない。
  `g?` (dired-summary) は決め打ちの一覧を出すだけで、この設定の割り当て (`f`、`o`、`h` など) とは食い違うので使わない。

## レッスン 1: 移動 (`1-move`)

| キー | 動作 |
|---|---|
| `j` / `k` | 下 / 上の行へ |
| `l` / `RET` | ディレクトリに入る / ファイルを開く |
| `h` (`-`) | 親ディレクトリへ戻る |
| `gg` / `G` | 先頭 / 末尾の行へ |
| `]]` / `[[` | 次 / 前のディレクトリの行へ |
| `J` | ファイル名を入力して、その行へ飛ぶ |
| `f` | `consult-find`: 今のディレクトリの下からファイルを探して開く |
| `q` | dired を閉じる (バッファも消える) |

- [ ] `l` で `a` → `b` → `c` と入り、`deep.txt` を開く。`SPC d RET` で dired に戻り、`h` を 3 回押して `1-move` に戻る。
- [ ] `]]` と `[[` で、ディレクトリの行 (`a`、`x`、`y`) だけを渡り歩く。
- [ ] `J` で `zz-last.txt` と入力して、その行に飛ぶ。
- [ ] `f` で `deep` と入力して、`deep.txt` を一気に開く。

`SPC d` は `dired` で、最初の候補は今開いているファイルのディレクトリになっている。
ファイルを開いたあと、その場所の dired に戻るときに使える。

## レッスン 2: 表示の切り替え (`2-view`)

| キー | 動作 |
|---|---|
| `(` | 権限・日付などの詳細を隠す / 表示する |
| `o` | 名前順と日付順を切り替える |
| `zh` | 隠しファイルを隠す / 表示する (自分の設定。今のバッファだけ) |
| `C-u o` | ls のオプションを直接書き換える (`-al` → `-l` で `zh` と同じ) |
| `s` | 印を付けた行を一覧から隠す。ファイルは消えない (印がないと何もしない) |
| `gr` | 読み直す (`s` で隠した行が戻る) |

- [ ] `(` を押して、ファイル名だけの表示にする。もう一度押して戻す。
- [ ] `o` で日付順にする。新しい順に並び、`old.txt` (2020 年) が下に来る。もう一度 `o` で名前順に戻す。
- [ ] `zh` で `.config`、`.history`、`.cache` を隠す。もう一度 `zh` で表示する。
- [ ] `C-u o` でオプションを `-l` に書き換えて、`zh` と同じ表示になることを確かめる。`h` で親に移ってから `l` で戻ると、隠しファイルがまた見える (変わるのはそのバッファだけ)。
- [ ] `middle.txt` に `m` で印を付け、`s` で一覧から隠す。`gr` で戻す。

`zh` と `C-u o` は、`o` で日付順にしていると名前順に戻る。

## レッスン 3: 印を付ける (`3-mark`)

`m` で付ける印は `*` で、「選んだ」という意味しか持たない。
何をするかは後で大文字のキー (`C` コピー、`R` 移動、`D` 削除など) で決める。

| キー | 動作 |
|---|---|
| `m` / `u` | 印を付ける / 外す |
| `U` | すべての印を外す |
| `t` (`~`) | 印を反転する |
| `*/` | ディレクトリに印を付ける |
| `* %` (`% m`) | ファイル名が正規表現に一致するものに印を付ける |
| `% g` | 中身が正規表現に一致するものに印を付ける |
| `M-}` / `M-{` | 次 / 前の印の付いた行へ |
| `* c` | 印の種類を変える (例: `* c * D` で `*` を削除の印 `D` に) |

- [ ] `memo.txt` と `plan.md` に `m` で印を付け、`u` で 1 つ外し、`U` で全部外す。
- [ ] `*/` で `figs` と `scripts` に印を付け、`t` で反転して、ファイルだけに印が付いた状態にする。`U` で外す。
- [ ] `* %` で `\.csv$` と入力して、CSV の 2 つに印を付ける。`U` で外す。
- [ ] `% g` で `TODO` と入力して、中身に TODO がある `memo.txt` と `plan.md` に印を付ける。`M-}` で印の行を順にたどる。
- [ ] そのまま `* c` で `*` を `D` に変えてみる (レッスン 4 の予習。ここでは `x` を押さない)。`U` で外す。

正規表現は Emacs の書き方で、ファイル名 (パスではない) に対して照合される。

## レッスン 4: 削除 (`4-delete`)

削除には 2 つの流れがある。

- `d` → `x`: 削除の印 `D` を付けていき、最後に `x` でまとめて消す。一覧を見直してから消せる。
- `m` → `D`: `*` の印 (なければカーソル行) をその場で消す。選んだものを消すとき、1 つだけ消すとき。

2 つの印は別物で、`x` は `D` の印だけ、`D` は `*` の印だけを処理する。

| キー | 動作 |
|---|---|
| `d` | 削除の印 `D` を付ける |
| `x` | `D` の印の付いたファイルを消す |
| `% d` | ファイル名が正規表現に一致するものに `D` の印を付ける |
| `#` | 自動保存ファイル (`#...#`) に `D` の印を付ける |
| `D` | `*` の印の付いたファイル (なければカーソル行) を消す |

- [ ] `junk.txt` に `d` を付けて、`x` で消す。
- [ ] `% d` で `\.bak$` と入力し、`old1.bak` から `old3.bak` に印を付けて、`x` で消す。
- [ ] `#` で `#draft.txt#` に印を付けて、`x` で消す。
- [ ] `% d` で `~$` と入力し、`report.txt~` に印を付けて、`x` で消す。
      (素の Emacs ではバックアップファイルの印は `~` だが、evil-collection では `~` が印の反転なので使えない)
- [ ] `tmp-a.log` と `tmp-b.log` に `m` で印を付けて、`D` で消す。
- [ ] 印を付けずに `draft.txt` の行で `D` を押して消す。

最後に残るのが `keep.md` と `report.txt` だけなら成功。

## レッスン 5: コピー・移動・作成 (`5-copy-move`)

| キー | 動作 |
|---|---|
| `C` | コピー |
| `R` | 移動・名前の変更 |
| `+` | ディレクトリを作る |
| `SPC 3` / `SPC 1` | 左右に分割 / 分割をやめる |
| `SPC h` / `SPC l` | 左 / 右のウィンドウへ |

`dired-dwim-target` を有効にしているので、dired を 2 つ並べているときは、
`C` や `R` の送り先の初期値がもう一方の dired のディレクトリになる。

- [ ] `5-copy-move` で `+` を押し、`backup` というディレクトリを作る。
- [ ] `src` に入り、`rename-me.txt` を `R` で `renamed.txt` に変える。
- [ ] `analysis.R` と `main.py` に印を付け、`C` で `../dst/` にコピーする。
- [ ] `SPC 3` で左右に分け、右のウィンドウで `h` と `l` を使って `dst` に移る。左に戻って `memo.md` で `R` を押すと、
      送り先の初期値が `dst` になっている。そのまま `RET` で移動する。`SPC 1` で分割をやめる。

最後に `src` が `analysis.R`、`main.py`、`renamed.txt`、`dst` が `analysis.R`、`main.py`、`memo.md` なら成功。

同じファイルシステムの中なら、`R` は中身の大きさに関係なく一瞬で終わる (ディレクトリも同じ)。
`R` で移動すると、移動したファイルを開いているバッファの保存先も付け替わる。

## レッスン 6: 名前の一括変更 (`6-rename`)

| キー | 動作 |
|---|---|
| `% R` | 正規表現で名前を変える (印の付いたファイル、なければカーソル行が対象) |
| `i` (`C-x C-q`) | wdired: 一覧をそのまま編集して名前を変える |
| `ZZ` (`C-c C-c`) | wdired の変更を確定する |
| `ZQ` (`C-c C-k`) | wdired の変更を取り消す |

- [ ] `photos` に入る。`* %` で `^IMG` と入力して 5 つに印を付け、`% R` で
      `IMG_0*\([0-9]+\)\.JPG` → `photo-\1.jpg` と入力する。1 つずつ確認されるので、`!` で残りを全部変える。
      `photo-1.jpg` から `photo-5.jpg` になれば成功。
- [ ] `chapters` に入る。`i` で wdired にし、evil の置換で 1 桁の章番号を 2 桁にする。

  ```
  :%s/ch\([0-9]\)\.md/ch0\1.md/
  ```

  `ZZ` で確定する。`ch01.md`、`ch02.md`、`ch03.md`、`ch09.md`、`ch10.md`、`ch11.md` になれば成功。
- [ ] もう一度 `i` で wdired にして適当に書き換え、`ZQ` で取り消せることを確かめる。

wdired では、ファイル名の部分だけが編集できる。`cw` や `.`、マクロなど evil の操作がそのまま使える。

## レッスン 7: サブディレクトリと一括検索・置換 (`7-project`)

| キー | 動作 |
|---|---|
| `I` | カーソル行のディレクトリを、同じ画面の下に展開する |
| `A` | 印の付いたファイルを正規表現で検索する (結果は xref の一覧) |
| `Q` | 印の付いたファイルを対象に、検索して置換する |

- [ ] `R`、`py`、`docs` の行でそれぞれ `I` を押し、3 つのディレクトリの中身を 1 つの画面で見る。
- [ ] `* %` で `\.R$` と入力し、`analysis.R` と `plot.R` に印を付ける (展開した中身にも印を付けられる)。
- [ ] `A` で `old_name` を検索し、一覧から該当行に飛べることを確かめる。
- [ ] 同じ印のまま `Q` で `old_name` を `new_name` に置換する。1 つずつ確認されるので、`y` か `!` で答える。
      置換したファイルはまだ保存されていないので、`C-x s` で保存する (`!` で全部保存)。

R の 2 ファイルだけが `new_name` になり、`main.py` と `memo.md` は `old_name` のままなら成功。
`Q` は、ディレクトリに印を付けるとその下のファイルすべてが対象になる。

もっと広い範囲を置換するなら、`consult-ripgrep` → `M-e` (embark-export) → wgrep のほうが向いている
(リポジトリの README の embark の節を参照)。

## レッスン 8: シェルコマンド・圧縮・比較 (`8-shell`)

| キー | 動作 |
|---|---|
| `!` | 印の付いたファイル (なければカーソル行) にシェルコマンドを実行する |
| `&` | `!` の非同期版 (Emacs が固まらない) |
| `c` | 印の付いたファイルを 1 つのアーカイブにまとめる (拡張子で形式が決まる) |
| `Z` | 1 つずつ圧縮 / 展開する |
| `=` | カーソル行のファイルと、入力したファイルの差分を見る |

`!` に渡すコマンドでは、`*` と `?` が特別な意味を持つ (前後に空白があるとき)。

- `*` を含む: ファイルの一覧を `*` の位置に入れて、1 回だけ実行する
- `?` を含む: ファイルごとに、名前を `?` の位置に入れて実行する
- どちらもない: ファイルごとに、名前を末尾に付けて実行する

- [ ] `log1.txt` と `log2.txt` に印を付け、`!` で `wc -l` と入力する (ファイルごとに実行される)。
- [ ] 同じ印のまま `!` で `cat * > all.txt` と入力し、1 つにまとめる。`gr` で `all.txt` ができたことを確かめる。
- [ ] `a.txt` と `b.txt` に印を付け、`c` で `fruits.tar.gz` と入力してまとめる。
- [ ] `log2.txt` で `Z` を押すと `log2.txt.gz` になる。もう一度 `Z` で戻す。
- [ ] `b.txt` の行で `=` を押し、`a.txt` を指定して差分を見る (みかん と バナナ の違い)。

重いファイルをファイルシステムをまたいで移動するときは、`R` だと Emacs が固まるので、
印を付けて `&` で `mv * /移動先/` と打つと、裏でシェルの `mv` を実行できる。
