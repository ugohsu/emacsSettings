# レッスン 1: 移動と開く (`01-move`)

| キー | 動作 |
|---|---|
| `j` / `k` | 下 / 上の行へ |
| `l` / `RET` | ディレクトリに入る / ファイルを開く |
| `h` (`-`) | 親ディレクトリへ戻る |
| `gg` / `G` | 先頭 / 末尾の行へ |
| `]]` / `[[` | 次 / 前のディレクトリの行へ |
| `J` | ファイル名を入力して、その行へ飛ぶ |
| `f` | 今のディレクトリの下からファイルを名前で探して開く (fd があれば `consult-fd`、なければ `consult-find`) |
| `gO` | 閲覧用に開く (`q` で dired に戻る) |
| `go` | 別のウィンドウで開く |
| `q` | dired を閉じる (バッファも消える) |
| `SPC d` | dired を開く (最初の候補は、今開いているファイルのディレクトリ) |

- [ ] `l` で `a` → `b` → `c` と入り、`deep.txt` を開く。`SPC d` → `RET` で `c` の dired に戻り、`h` を 3 回押して `01-move` に戻る。
- [ ] `]]` と `[[` で、ディレクトリの行 (`a`、`x`、`y`) だけを渡り歩く。
- [ ] `J` で `zz-last.txt` と入力して、その行に飛ぶ。`gg` で先頭に、`G` で末尾に移る。
- [ ] `notes.txt` の行で `gO` を押す。閲覧用に開くので、うっかり書き換えることがない。`q` で dired に戻る。
- [ ] `f` で `deep` と入力して、`deep.txt` を一気に開く。`SPC d` → `RET` で、その場所 (`a/b/c`) の dired が開く。
      `h` で `01-move` まで戻る。

`go` は左のウィンドウ (`00-tutor.md`) を使うので、ここでは試さない。
試したときは、左に移って (`SPC h`) `SPC b` で `00-tutor.md` を選べば戻る。
