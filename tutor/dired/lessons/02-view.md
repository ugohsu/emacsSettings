# レッスン 2: 表示の切り替え (`02-view`)

| キー | 動作 |
|---|---|
| `(` | 権限・日付などの詳細を隠す / 表示する |
| `o` | 名前順と日付順を切り替える |
| `zh` | 隠しファイル (`.` で始まる名前。`.` と `..` は除く) を表示する / 隠す (自分の設定。最初は隠れている。開いているすべての dired でまとめて切り替わる) |
| `C-u o` | ls のオプションを直接書き換える |
| `gr` | 読み直す (ほかのプログラムが作ったファイルなどを反映する) |

- [ ] `(` を押して、ファイル名だけの表示にする。もう一度押して戻す。
- [ ] `o` で日付順にする。新しい順に並び、`old.txt` (2020 年) が下に来る。もう一度 `o` で名前順に戻す。
- [ ] 隠しファイルは最初から隠れていて、モードライン (画面下の帯) に ` Omit` と出ている。`zh` を押すと、`.config`、`.history`、`.cache` が現れ、
      ` Omit` が消える。`.` と `..` は、隠しているあいだも出ている。
- [ ] 表示したまま `h` で親に移る。親でも、目印のファイル `.dired-tutor` が見えている (`zh` はすべての dired でまとめて切り替わり、
      そのあと開く dired もそれに従う)。`l` で `02-view` に戻り、`zh` で隠す。
- [ ] `o` で日付順にしてから `zh` で表示する。日付順のまま現れる。`zh` で隠す。
      `h` で親に移ってから `l` で戻ると、名前順に戻っている (並べ方は、そのバッファだけ)。
- [ ] `zh` で表示してから、`C-u o` でオプションを `-al` から `-l` に書き換える。ls が隠しファイルを出さなくなるので、
      `zh` で隠したときと同じように消える (こちらは `.` と `..` も消える)。もう一度 `C-u o` で `-al` に戻し、`zh` で隠す。

`zh` は一覧を作ったあとで行を隠すだけ (dired-x の dired-omit-mode) なので、並べ替えはそのまま保たれる。
ディレクトリを開くたびに、エコーエリアに `Omitted 3 lines in ~/dired-tutor/02-view/` のように、隠した数が出る。
`C-u o` は ls のオプションごと置き換えるので、`o` で日付順にしていると名前順に戻る。
