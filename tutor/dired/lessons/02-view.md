# レッスン 2: 表示の切り替え (`02-view`)

| キー | 動作 |
|---|---|
| `(` | 権限・日付などの詳細を隠す / 表示する |
| `o` | 名前順と日付順を切り替える |
| `zh` | 隠しファイル (`.` で始まる名前) を隠す / 表示する (自分の設定。今のバッファだけ) |
| `C-u o` | ls のオプションを直接書き換える |
| `gr` | 読み直す (ほかのプログラムが作ったファイルなどを反映する) |

- [ ] `(` を押して、ファイル名だけの表示にする。もう一度押して戻す。
- [ ] `o` で日付順にする。新しい順に並び、`old.txt` (2020 年) が下に来る。もう一度 `o` で名前順に戻す。
- [ ] `zh` で `.config`、`.history`、`.cache` を隠す。モードライン (画面下の帯) に ` Omit` と出る。もう一度 `zh` で表示する。
- [ ] `o` で日付順にしてから `zh` で隠す。日付順のまま隠れる。
      `h` で親に移ってから `l` で戻ると、隠しファイルがまた見え、名前順に戻っている (変わるのはそのバッファだけ)。
- [ ] `C-u o` でオプションを `-al` から `-l` に書き換える。ls が隠しファイルを出さなくなるので、`zh` と同じように消える。
      もう一度 `C-u o` で `-al` に戻す。

`zh` は一覧を作ったあとで行を隠すだけ (dired-x の dired-omit-mode) なので、並べ替えはそのまま保たれる。
`C-u o` は ls のオプションごと置き換えるので、`o` で日付順にしていると名前順に戻る。
