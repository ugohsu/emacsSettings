# レッスン 3: 印の基本と、印を付けて消す (`03-mark`)

`m` で付ける印は `*` で、「選んだ」という意味しか持たない。何をするかは、あとで大文字のキーで決める。

| 操作のキー | 動作 | 練習するレッスン |
|---|---|---|
| `D` | 消す | このレッスンと 6 |
| `C` / `R` | コピー / 移動・名前の変更 | 7 |
| `% R` | 正規表現で名前を変える | 8 |
| `A` / `Q` | 中身を検索 / 置換 | 9 |
| `!` / `&` | シェルコマンドを実行 | 10 |
| `c` / `Z` | まとめて圧縮 / 1 つずつ圧縮・展開 | 10 |
| `r` | 選んだ外部アプリで開く | 10 |
| `Y` | ファイル名をコピー | 5 |

どの操作も同じ決まりで対象が決まる。

- 印の付いたファイルがあれば、それが対象になる (カーソル行は関係ない)
- 印がなければ、カーソル行のファイルだけが対象になる
- 印は操作のあとも残る (消したファイルの印は消える)。同じ選び方のまま、続けて別の操作ができる

| キー | 動作 |
|---|---|
| `m` | 印を付けて、次の行へ (`3m` で 3 行まとめて) |
| `u` | 印を外して、次の行へ |
| `U` | すべての印を外す |
| `t` (`~`) | 印を反転する (`.`・`..` には付かない) |
| `V` → `j` / `k` → `m` | 範囲を選んで、まとめて印を付ける |
| `M-}` / `M-{` | 次 / 前の印の付いた行へ |
| `D` | 印の付いたファイル (なければカーソル行) を消す |

## 付ける・外す

- [ ] `apple.txt` で `m` を 2 回押し、`apple.txt` と `banana.txt` に印を付ける (行頭に `*` が出る)。
      `k` で `banana.txt` に戻って `u` で外し、`U` で全部外す。
- [ ] `cherry.txt` で `3m` を押す。`cherry.txt`・`date.txt`・`elderberry.txt` に印が付く。`U` で外す。
- [ ] `apple.txt` で `V` を押し、`j` で `banana.txt` まで広げて `m` を押す。選んだ 2 つに印が付き、normal state に戻る。`U` で外す。
- [ ] `keep.md` に `m` で印を付けて `t` を押す。`keep.md` の印が外れ、ほかのすべて (`box` も) に付く。
      「〜以外」を選ぶときに使う。`U` で外す。
- [ ] `apple.txt`・`date.txt`・`grape.txt` に印を付け、`gg` で先頭に移ってから `M-}` を何度か押して、印の行を順にたどる。
      `M-{` で逆にたどる。印は次の課題で使うので、外さない。

## 印が残るとき・消えるとき

- [ ] 印を付けたまま `o` で日付順にし、もう一度 `o` で戻す。`gr` で読み直す。どちらでも印は残っている。
- [ ] `box` に `l` で入り、`h` で戻る。印が消えている。この設定では、別のディレクトリに移ると dired のバッファを閉じて
      作り直すため。いくつものディレクトリにまたがって選ぶ方法は、レッスン 5 (`I`) とレッスン 11 (`f` → `M-e`) で練習する。

## 印を付けて消す

- [ ] `fig.txt` と `grape.txt` に印を付けて `D` を押す。消す対象の一覧が出て、`Delete * [2 files]` と確認されるので `y` で答える。
- [ ] 印を付けずに、`date.txt` の行で `D` を押す。`Delete date.txt` と、カーソル行のファイルだけが確認される。`y` で消す。
- [ ] `apple.txt` で `V` → `j` と選び、`m` で印に変えてから `D` で消す (`apple.txt` と `banana.txt`)。

最後に `cherry.txt`・`elderberry.txt`・`keep.md`・`box` が残れば成功。

**範囲を選んだまま `D` を押さない。** 印を付ける `m` は選んだ範囲に効くが、`D`・`C`・`R` などの操作は範囲を見ずに、
カーソルのある 1 つのファイルだけを対象にする。しかも evil が選択を行末まで広げるので、下に向かって選んだときは、
選択の**次の行**のファイルが対象になる (`apple.txt`〜`banana.txt` を選んで `D` を押すと、`box` を消しにいく)。
範囲で選んだら、必ず `m` で印に変えてから操作する。確認に出るファイル名を見る習慣も付けておく。
