# レッスン 4: 条件で印を付ける (`04-mark-by`)

1 つずつ `m` で選ぶ代わりに、拡張子・名前・中身・種類・大きさなどの条件で、まとめて印を付ける。

| キー | 印を付けるもの |
|---|---|
| `* .` | 指定した拡張子のもの (初期値はカーソル行のファイルの拡張子。`RET` でそのまま使える。dired-x) |
| `% m` (`* %`) | ファイル名が正規表現に一致するもの |
| `% g` | 中身が正規表現に一致するもの |
| `* /` | ディレクトリ |
| `* *` | 実行できるファイル |
| `* @` | シンボリックリンク |
| `* (` | Lisp の式が成り立つもの (例: `(= size 0)` で空のファイル。dired-x) |
| `C-u` を先に押す | 条件に合うものの印を、付ける代わりに外す (`C-u % m`、`C-u * .` など) |

条件は組み合わせられる。

- 続けて別の条件で付けると、印が足される (「A か B」)
- `C-u` を付けて外すと、印が減る (「A のうち、B でないもの」)
- `t` で反転すると、それ以外になる (「A でないもの」)

各課題の終わりに `U` で印を外しておく。

- [ ] `* .` で `csv` と入力する。CSV の 3 つ (`data-2024.csv`・`data-2025.csv`・`summary.csv`) に印が付く。
- [ ] `memo.txt` の行で `* .` を押す。初期値が `txt` なので、そのまま `RET` で `.txt` の 3 つ
      (`empty1.txt`・`memo.txt`・`memo2.txt`) に印が付く。
- [ ] `% m` で `^data-` と入力して 2 つに印を付け、続けて `% m` で `^memo` と入力する。印が足されて 4 つになる。
- [ ] `* .` で `csv` の 3 つに印を付けてから、`C-u % m` で `2024` と入力する。`data-2024.csv` の印だけが外れる
      (「CSV のうち、2024 でないもの」)。
- [ ] `% g` で `TODO` と入力する。中身に TODO がある `memo.txt` と `plan.md` に印が付く。
- [ ] `* /` でディレクトリ (`figs`・`old`)、`* *` で実行できるファイル (`run.sh`)、`* @` でシンボリックリンク (`latest`) に、
      それぞれ印を付ける (毎回 `U` で外す)。
- [ ] `% m` で `^\.` と入力する。隠しファイル `.env-old` に印が付く (`.` と `..` には付かない)。
- [ ] `* .` で `md` と入力して `t` を押す。`.md` 以外のすべてに印が付く。
- [ ] `* (` で `(= size 0)` と入力する。空のファイル (`empty1.txt`・`empty2.log`) に印が付く。そのまま `D` で消す。

`empty1.txt` と `empty2.log` が消えていれば成功。

## キーのまとめ方

`*` と `%` で始まるキーは、別々の考え方でまとめてある。

- `*` は「印を扱う」もの: 何で選ぶかにかかわらず、印を付ける・外す・反転する・印の行へ移る
  (`* m`、`* u`、`* .`、`* /`、`* *`、`* @`、`* (`、`* t`、`* c` (レッスン 5)、`* s` (レッスン 5) など)。
- `%` は「正規表現 (ファイル名のパターン) を使う」もの: 正規表現で選ぶか、名前を規則で変える
  (`% m`、`% g`、`% R`・`% C` (正規表現で名前を決めて移動・コピー。レッスン 8)、`% u`・`% l` (大文字・小文字に) など)。

「正規表現で印を付ける」はどちらにも当てはまるので、`* %` と `% m` の 2 つのキーで同じコマンド (`dired-mark-files-regexp`) を呼べる。

## 正規表現と式の注意

- 正規表現は Emacs の書き方で、ファイル名 (パスではない) に対して照合される。`.` は任意の 1 文字なので、
  拡張子を正規表現で書くときは `\.csv$` のようにする (拡張子だけなら `* .` のほうが短い)。
- `* (` の式では、`size` (バイト数)、`name` (ファイル名)、`mode` (`-rw-r--r--` のような権限の文字列)、
  `time` (一覧に出ている日時の文字列) などが使える。ディレクトリの `size` は 4096 などになるので、
  `(> size 1000)` のように書くと、ディレクトリや `.`・`..` にも印が付く。ファイルだけにするときは
  `(and (> size 1000) (string-prefix-p "-" mode))` と書く。`D` を押す前に、印の付いた行を確かめる。
