# レッスン 5: 印を使いこなす (`05-mark-more`)

| キー | 動作 |
|---|---|
| `s` | 印を付けた行を一覧から隠す (ファイルは消えない。`gr` で戻る) |
| `* c` | 印の種類を変える (`* c` → 元の印 → 新しい印。例: `* c * 1` で `*` を `1` に) |
| `* ?` (`M-DEL`) | 指定した種類の印だけを外す (`*` を押せば `*` だけ、`RET` ならすべて) |
| `I` | カーソル行のディレクトリを、同じ画面の下に展開する |
| `* s` | カーソルのあるディレクトリ (展開したものを含む) のファイルすべてに印を付ける |
| `Y` / `C-u Y` | 印の付いたファイルの名前を、空白区切りでコピーする (`C-u` を付けると `old/a.csv` のような相対パス) |
| `M-x dired-number-of-marked-files` | 印の付いたファイルの数と合計サイズを表示する |

## 選んだものだけを表示する

`s` は印を付けた行を隠す。`t` と組み合わせると、選んだものだけを表示できる (一覧の絞り込み)。

- [ ] `% m` で `2025` と入力し、2025 年の CSV 2 つに印を付ける。`t` で反転して `s` を押すと、
      ほかの行が隠れて、`r-2025-01.csv` と `r-2025-02.csv` だけが残る (`.`・`..` は残る)。
- [ ] 残った 2 つは印が外れている (`t` で反転したため)。もう一度 `t` を押すと、見えている 2 つだけに印が付く。
      ここで操作のキーを押せば、この 2 つが対象になる。
- [ ] `gr` で読み直すと、隠した行が戻る。2025 年の 2 つの印は残っている。`U` で外す。

## 印を退避する: 2 つの選び方を同時に持つ

印の文字は `*` だけでなく、好きな 1 文字を使える。操作のキーが対象にするのは `*` の印だけなので、
ほかの文字に変えておけば、その選び方を残したまま、別のものを `*` で選んで操作できる。

ここでは「下書きの `.md` は後で消す」と決めておいてから、先に「CSV を `archive` にコピーする」。

- [ ] `% m` で `^draft` と入力し、`draft1.md` と `draft2.md` に印を付ける。
- [ ] `* c` を押す。`Change (old mark):` と聞かれたら `*` を、`Change * marks to (new mark):` と聞かれたら `1` を押す。
      2 つの印が `1` に変わる。
- [ ] `* .` で `csv` と入力し、CSV の 4 つに `*` の印を付ける。`1` の印はそのまま残っている。
- [ ] `C` を押し、送り先に `archive/` と入力してコピーする。コピーされるのは `*` の 4 つだけ。コピーのあとも `*` の印は残る。
- [ ] `* ?` を押し、`Remove marks (RET means all):` と聞かれたら `*` を押す。`*` の印だけが外れ、`1` は残る
      (`U` だとすべての印が外れる)。
- [ ] `* c` → `1` → `*` で、下書きの印を `*` に戻す。`D` で 2 つを消す。

`archive` に CSV が 4 つ入り、`draft1.md` と `draft2.md` が消えていれば成功。

## いくつものディレクトリにまたがって印を付ける

この設定では、別のディレクトリに移ると印が消える (レッスン 3)。いくつものディレクトリから選ぶときは、
`I` で 1 つのバッファに並べてから印を付ける (もっと広い範囲から集めるなら、レッスン 11 の `f` → `M-e`)。

- [ ] `old` の行で `I` を押す。`old` の中身が下に展開され、カーソルがそちらに移る。
      `h` を押すと、上の一覧の `old` の行に戻る。`k` で 1 つ上の `new` の行に移り、もう一度 `I` を押す。
- [ ] `* .` で `csv` と入力する。上の一覧と、展開した `old`・`new` のすべての CSV に印が付く。
- [ ] `M-x dired-number-of-marked-files` を実行する。印の数 (7) と合計サイズが表示される。
- [ ] `C-u Y` を押して、印の付いたファイルの名前をコピーする。コピーした内容は画面の一番下に表示される。
      `old/a.csv` のように、今のディレクトリからの相対パスになっている (`C-u` を付けないと `a.csv` のように名前だけ)。
- [ ] `U` で外す。`old` の中のファイルの行 (`a.csv` など) に移って `* s` を押す。`old` の中のファイルだけに印が付く。`U` で外す。

展開した中で `h` を押すと、親ディレクトリには移らず、同じバッファの上の一覧の、そのディレクトリの行 (`old` など) に戻る。
展開をやめるには、`gg` で先頭に戻ってから `h` で親に移り、`l` で入り直す (`gr` では展開したまま)。
