# レッスン 6: 消す・片付ける (`06-delete`)

消すときも、レッスン 3〜5 と同じく印を付けて `D` を押す。消したファイルはゴミ箱に入らないので、確認に出る名前をよく見る。

| キー | 動作 |
|---|---|
| `D` | 印の付いたファイル (なければカーソル行) を消す |
| `% m` で `~$` | バックアップファイル (`foo~`) に印を付ける |
| `% m` で `^#` | 自動保存ファイル (`#foo#`) に印を付ける |
| `% &` | 中間ファイル (`.aux`・`.log`・`.toc`・`.bak`・`.dvi` など) に削除の印 (flag) を付ける |
| `x` | 削除の印 (flag) の付いたファイルを消す |

## ディレクトリを消す

- [ ] `empty-dir` の行で `D` を押す。空のディレクトリは、`Delete empty-dir` の確認 1 回で消える。
- [ ] `old-project` の行で `D` を押す。`Delete old-project` に `y` で答えると、中身があるので
      `Recursively delete old-project?` ともう一度聞かれる。`y` で中身ごと消す。

いくつものディレクトリに印を付けて消すときは、2 回目の確認で `!` と答えると、残りのディレクトリは聞かずに中身ごと消す
(`n` はそのディレクトリだけ飛ばす、`q` はやめる)。

## バックアップファイル・自動保存ファイルを片付ける

Emacs は、ファイルを保存するときに元の内容を `foo~` (バックアップ) に残し、編集中は `#foo#` (自動保存) を作ることがある。

- [ ] `% m` で `~$` と入力して `report.txt~` に印を付け、`D` で消す。
- [ ] `% m` で `^#` と入力して `#draft.txt#` に印を付け、`D` で消す。

## 削除の印 (flag): 読めればよい

dired には、印 `*` とは別に、削除専用の印 `D` (flag) がある。`d` で付けて `x` でまとめて消す。
このチュートリアルでは使わないが、掃除用のコマンドのいくつかは flag を付けるので、読み方だけ覚える。

- `x` は flag `D` の付いたファイルだけを消す。`*` の印は見ない
- キーの `D` は `*` の印の付いたファイルを消す。flag は見ない
- `U` は、どちらの印も外す。`t` (反転) は flag には触れない

flag を付けるコマンド: `% &` (中間ファイル)、`#` (自動保存ファイル)、`% d` (正規表現)、`.` (古い番号付きバックアップ)、`d`。

- [ ] `% &` を押す。`paper.aux`・`paper.log`・`paper.toc` の行頭に `D` が付く (`paper.tex` には付かない)。
      `x` を押し、`Delete D [3 files]` の確認に `y` で答えて消す。

flag を付けたけれど消すのをやめるときは、`U` で外す。flag を `*` の印に変えて、ほかの操作に使うこともできる
(`* c` → `D` → `*`。レッスン 5 の印の種類の変え方)。

最後に `draft.txt`・`keep.md`・`paper.tex`・`report.txt` が残れば成功。
