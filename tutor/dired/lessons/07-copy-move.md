# レッスン 7: コピー・移動・作成 (`07-copy-move`)

| キー | 動作 |
|---|---|
| `C` | 印の付いたファイル (なければカーソル行) をコピーする |
| `R` | 移動する・名前を変える |
| `+` | ディレクトリを作る |
| `SPC 3` / `SPC 0` | 今のウィンドウを左右に分ける / 今のウィンドウを閉じる |
| `SPC h` / `SPC l` | 左 / 右のウィンドウへ |

送り先は入力欄で指定する。ファイル 1 つなら新しい名前も書ける。いくつかなら、送り先はディレクトリになる。
`dired-dwim-target` を有効にしているので、dired を 2 つ並べているときは、
`C` や `R` の送り先の初期値がもう一方の dired のディレクトリになる。

- [ ] `07-copy-move` で `+` を押し、`backup` というディレクトリを作る。
- [ ] `src` に入り、`rename-me.txt` の行で `R` を押して `renamed.txt` と入力し、名前を変える。
- [ ] `analysis.R` と `main.py` に印を付け、`C` で `../dst/` にコピーする。コピーのあとも印は残っているので、
      そのまま `C` で `../backup/` にもコピーする。`U` で外す。
- [ ] 右の dired で `SPC 3` を押して左右に分け (左の `00-tutor.md` と合わせて 3 つになる)、一番右のウィンドウで
      `h` と `l` を使って `dst` に移る。`SPC h` で真ん中に戻って `memo.md` で `R` を押すと、送り先の初期値が `dst` になっている。
      そのまま `RET` で移動する。`SPC 0` で真ん中のウィンドウを閉じて、2 つに戻す
      (`SPC 1` はほかのウィンドウをすべて閉じるので、`00-tutor.md` も消える)。

最後に `src` が `analysis.R`・`main.py`・`renamed.txt`、`dst` が `analysis.R`・`main.py`・`memo.md`、
`backup` が `analysis.R`・`main.py` なら成功。

同じファイルシステムの中なら、`R` は中身の大きさに関係なく一瞬で終わる (ディレクトリも同じ)。
`R` で移動すると、移動したファイルを開いているバッファの保存先も付け替わる。
