# レッスン 1: 移動 (`1-move`)

| キー | 動作 |
|---|---|
| `j` / `k` | 下 / 上の行へ |
| `l` / `RET` | ディレクトリに入る / ファイルを開く |
| `h` (`-`) | 親ディレクトリへ戻る |
| `gg` / `G` | 先頭 / 末尾の行へ |
| `]]` / `[[` | 次 / 前のディレクトリの行へ |
| `J` | ファイル名を入力して、その行へ飛ぶ |
| `f` | `consult-find`: 今のディレクトリの下からファイルを探して開く |
| `q` | dired を閉じる (バッファも消える) |

- [ ] `l` で `a` → `b` → `c` と入り、`deep.txt` を開く。`SPC d RET` で dired に戻り、`h` を 3 回押して `1-move` に戻る。
- [ ] `]]` と `[[` で、ディレクトリの行 (`a`、`x`、`y`) だけを渡り歩く。
- [ ] `J` で `zz-last.txt` と入力して、その行に飛ぶ。
- [ ] `f` で `deep` と入力して、`deep.txt` を一気に開く。

`SPC d` は `dired` (開いた場所を zoxide に記録する) で、最初の候補は今開いているファイルのディレクトリになっている。
ファイルを開いたあと、その場所の dired に戻るときに使える。
