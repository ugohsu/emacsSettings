# レッスン 10: おまけ (どのディレクトリでも)

| キー | 動作 |
|---|---|
| `Y` | ファイル名をコピーする |
| `SPC y p` / `SPC y d` / `SPC y n` | カーソル行のファイルの絶対パス / ディレクトリ / ファイル名をコピーする (自分の設定) |
| `zz` | zoxide に記録されたディレクトリを選んで dired で開く (よく使う順。打って絞り込む。元の dired は残るので `SPC b` で戻れる) |
| `SPC z` | `zz` と同じ (dired の外からでも使える) |
| `SPC :` | 今のディレクトリで eat (ターミナル) を開く |
| `M-h` | 今のバッファで使えるキーとコマンドの一覧 (embark-bindings。絞り込んで実行もできる) |
