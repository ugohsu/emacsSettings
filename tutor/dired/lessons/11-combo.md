# レッスン 11: consult・embark と組み合わせる (`11-combo`)

dired だけでは手間のかかる「あちこちのディレクトリに散らばったファイルをまとめて扱う」
「dired を開かずにファイルを操作する」といった作業を、consult と embark で補う。

| キー | 動作 |
|---|---|
| `f` → `M-e` | `f` (`consult-fd` か `consult-find`) で探した結果を dired の一覧に書き出す (embark-export) |
| `SPC a` | カーソル行のファイルやディレクトリに embark のアクションを実行する |
| `F` | ファイルの中身を検索する (`consult-ripgrep` か `consult-grep`)。印があれば、印の付いたファイル・ディレクトリの中だけ |
| `F` → `M-e` | 検索の結果を grep の一覧に書き出す (embark-export)。wgrep で書き換えられる |
| `SPC a` → `C r` | カーソル行のディレクトリの中だけを `consult-ripgrep` で検索する (印を付けずに 1 つのディレクトリを選ぶとき) |
| `f`・`F` で `語#` | 2 文字以下の語でも、後ろに `#` を打てばすぐ検索する (ふだんは 3 文字打つまで検索しない) |
| `f` → `.#` | 下にあるファイルとディレクトリを全部出す (`find .` にあたる)。続けて `#` の後ろに打てば、その中から絞り込む |
| `M-a` | ミニバッファの補完中に、選択中の候補に embark のアクションを実行する |
| `M-a` → `j` | 候補のファイルの場所を dired で開き、その行にカーソルを置く |
| `M-a` → `r` / `d` | 候補のファイルの名前を変える / 消す (dired を開かずに) |
| `M-a` → `x` | 候補のファイルを、選んだ外部アプリで開く (dired の `r` と同じ。自分の設定) |

## 散らばったファイルを集める

- [ ] `11-combo` で `f` を押し、`csv` と入力する。`2024/jan`、`2024/feb`、`2025/mar` にある 3 つの CSV が候補に出る。
- [ ] そのまま `M-e` を押す。3 つの CSV だけが並んだ dired (`*Embark Export Dired ...*`) が開く。
- [ ] この一覧は普通の dired として使える。`t` で全部に印を付け、`R` で `collected/` に移動する
      (送り先の入力欄の末尾に `collected/` を足して `RET`)。

`collected` に `sales-2024-01.csv`、`sales-2024-02.csv`、`sales-2025-03.csv` が入れば成功。

## 散らばった一時ファイルを消す

- [ ] `11-combo` で `f` → `tmp` → `M-e` と押し、`.tmp` のファイル 3 つだけの dired を作る。
- [ ] `* .` で `tmp` と入力して印を付け (`t` で全部に付けてもよい)、`D` で消す。

書き出した一覧でも、レッスン 3〜8 の操作 (条件での印、`D`、`C`、`% R`、wdired など) がそのまま使える。
別々のディレクトリにあるファイルを 1 つの一覧で選べるので、レッスン 5 の `I` よりも広い範囲から集められる。

## 中身で探して、見ながら書き換える

- [ ] `11-combo` で、印を付けずに `F` を押し、`締め切り` と入力する。`11-combo` の下全部が対象になり、
      `docs` の 2 ファイルと `2024/feb/notes.md` の 3 か所が出る。`C-g` でやめる。
- [ ] `docs` の行で `m` を押して印を付け、もう一度 `F` → `締め切り` と押す。
      今度は `docs` の中の 2 ファイルだけが出て、`2024/feb/notes.md` は出ない (印の付いたディレクトリは、その下が対象になる)。
- [ ] そのまま `M-e` で grep の一覧に書き出し、`C-c C-p` で編集できる状態 (wgrep) にする。
      2 か所の `締め切り` を `〆切` に書き換え、`C-c C-c` で各ファイルに反映する。
      最後に `M-x save-some-buffers` (`!` で全部) で保存する。
- [ ] `U` で印を外し、`docs` の行で `SPC a` → `C r` と押して `〆切` と入力する。
      印を付けなくても、カーソル行のディレクトリの中だけを検索できる。

`F` も、レッスン 9 の `A`・`Q` と同じく印の付いたファイル・ディレクトリが対象になる (印がなければ、このディレクトリの下全部)。
打つたびに結果が変わり、一覧で見ながら手で直せるので、置き換え方が場所によって違うときは `F` → `M-e` のほうが向いている。

## find | xargs grep のようにつなぐ

`f` で名前で探して `M-e` で dired に書き出し、印を付けて `F` で中身を検索する。
シェルの `find . -name '*py*' | xargs grep pandas` と同じことを、途中の一覧を見ながら 1 段ずつやる。

- [ ] `11-combo` で `f` を押し、`py` と打つ。まだ何も出ない (外部コマンドは 3 文字打つまで動かない)。
      続けて `#` を打つと (入力欄は `#py#` になる)、すぐに fd が動いて `.py` のファイル 4 つが出る。
- [ ] 先頭の `#` を残して `py#` を消し、`.#` と打ち直す (入力欄は `#.#`。先頭の `#` まで消すと、先頭の `.` が区切りの記号になってしまう)。`11-combo` の下のファイルとディレクトリが全部出る。
      そのまま `py` と続けると (`#.#py`)、fd を動かし直さずに、出ている候補の中から絞り込む。
- [ ] `#py#` に戻して `M-e` を押し、`.py` の 4 つだけの dired を作る (`find` の結果にあたる)。
- [ ] `t` で全部に印を付け、`F` → `pandas` と押す。`load.py`・`clean.py`・`report.py` の 3 か所が出る (`| xargs grep pandas` にあたる)。
      `docs/todo.md` にも `pandas` があるが、最初の `f` で `.py` に絞っているので出ない。`C-g` でやめる。
- [ ] さらにつなぐ (`| xargs grep -l pandas | xargs grep TODO` にあたる)。`F` の結果を `M-e` で書き出すと
      grep の一覧になり、印は付けられない。そこで、書き出した dired のまま `U` で印を外し、`% g` で `pandas` と入力して、
      中身に `pandas` を含むファイルにだけ印を付ける。
- [ ] そのまま `F` → `TODO` と押す。`load.py` と `report.py` の 2 か所だけが出る
      (`plot.py` にも `TODO` はあるが、`pandas` を使っていないので外れる)。`M-e` で grep の一覧に書き出す。

`% g` で印を付け直せば、何段でもつなげる。印を付けたあと `t` → `s` と押すと、印のないファイルを一覧から隠して、残ったものだけを見られる。

`M-a` → `j` (embark-dired-jump) は、「今のファイルの場所を dired で開く」`C-x C-j` (dired-jump。
この設定では SKK に使っている) の代わりになる。
