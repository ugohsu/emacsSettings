# レッスン 3: 印を付ける (`3-mark`)

`m` で付ける印は `*` で、「選んだ」という意味しか持たない。
何をするかは後で大文字のキー (`C` コピー、`R` 移動、`D` 削除など) で決める。

| キー | 動作 |
|---|---|
| `m` / `u` | 印を付ける / 外す |
| `U` | すべての印を外す |
| `t` (`~`) | 印を反転する |
| `*/` | ディレクトリに印を付ける |
| `* %` (`% m`) | ファイル名が正規表現に一致するものに印を付ける |
| `% g` | 中身が正規表現に一致するものに印を付ける |
| `M-}` / `M-{` | 次 / 前の印の付いた行へ |
| `* c` | 印の種類を変える (例: `* c * D` で `*` を削除の印 `D` に) |

`*` と `%` で始まるキーは、別々の考え方でまとめてある。

- `*` は「印を扱う」もの: 何で選ぶかにかかわらず、印を付ける・外す・反転する・数える・印の行へ移る
  (`* m`、`* u`、`* /`、`* *` (実行ファイル)、`* @` (シンボリックリンク)、`* t`、`* c`、`* N` (数える) など)。
- `%` は「正規表現 (ファイル名のパターン) を使う」もの: 正規表現で選ぶか、名前を規則で変える
  (`% m`、`% g`、`% d` (レッスン 4)、`% R`・`% C` (正規表現で名前を決めて移動・コピー。レッスン 6)、`% u`・`% l` (大文字・小文字に) など)。

「正規表現で印を付ける」はどちらにも当てはまるので、`* %` と `% m` の 2 つのキーで同じコマンド (`dired-mark-files-regexp`) を呼べる。
`% g` と `% d` も正規表現で印を付けるが、`*` 側にはキーがない。

- [ ] `memo.txt` と `plan.md` に `m` で印を付け、`u` で 1 つ外し、`U` で全部外す。
- [ ] `*/` で `figs` と `scripts` に印を付け、`t` で反転して、ファイルだけに印が付いた状態にする。`U` で外す。
- [ ] `* %` で `\.csv$` と入力して、CSV の 2 つに印を付ける。`U` で外す。
- [ ] `% g` で `TODO` と入力して、中身に TODO がある `memo.txt` と `plan.md` に印を付ける。`M-}` で印の行を順にたどる。
- [ ] そのまま `* c` で `*` を `D` に変えてみる (レッスン 4 の予習。ここでは `x` を押さない)。`U` で外す。

正規表現は Emacs の書き方で、ファイル名 (パスではない) に対して照合される。
