# レッスン 5: コピー・移動・作成 (`5-copy-move`)

| キー | 動作 |
|---|---|
| `C` | コピー |
| `R` | 移動・名前の変更 |
| `+` | ディレクトリを作る |
| `SPC 3` / `SPC 1` | 左右に分割 / 分割をやめる |
| `SPC h` / `SPC l` | 左 / 右のウィンドウへ |

`dired-dwim-target` を有効にしているので、dired を 2 つ並べているときは、
`C` や `R` の送り先の初期値がもう一方の dired のディレクトリになる。

- [ ] `5-copy-move` で `+` を押し、`backup` というディレクトリを作る。
- [ ] `src` に入り、`rename-me.txt` を `R` で `renamed.txt` に変える。
- [ ] `analysis.R` と `main.py` に印を付け、`C` で `../dst/` にコピーする。
- [ ] `SPC 3` で左右に分け、右のウィンドウで `h` と `l` を使って `dst` に移る。左に戻って `memo.md` で `R` を押すと、
      送り先の初期値が `dst` になっている。そのまま `RET` で移動する。`SPC 1` で分割をやめる。

最後に `src` が `analysis.R`、`main.py`、`renamed.txt`、`dst` が `analysis.R`、`main.py`、`memo.md` なら成功。

同じファイルシステムの中なら、`R` は中身の大きさに関係なく一瞬で終わる (ディレクトリも同じ)。
`R` で移動すると、移動したファイルを開いているバッファの保存先も付け替わる。
