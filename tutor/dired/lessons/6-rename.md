# レッスン 6: 名前の一括変更 (`6-rename`)

| キー | 動作 |
|---|---|
| `% R` | 正規表現で名前を変える (印の付いたファイル、なければカーソル行が対象) |
| `i` (`C-x C-q`) | wdired: 一覧をそのまま編集して名前を変える |
| `ZZ` (`C-c C-c`) | wdired の変更を確定する |
| `ZQ` (`C-c C-k`) | wdired の変更を取り消す |

- [ ] `photos` に入る。`* %` で `^IMG` と入力して 5 つに印を付け、`% R` で
      `IMG_0*\([0-9]+\)\.JPG` → `photo-\1.jpg` と入力する。1 つずつ確認されるので、`!` で残りを全部変える。
      `photo-1.jpg` から `photo-5.jpg` になれば成功。
- [ ] `chapters` に入る。`i` で wdired にし、evil の置換で 1 桁の章番号を 2 桁にする。

  ```
  :%s/ch\([0-9]\)\.md/ch0\1.md/
  ```

  `ZZ` で確定する。`ch01.md`、`ch02.md`、`ch03.md`、`ch09.md`、`ch10.md`、`ch11.md` になれば成功。
- [ ] もう一度 `i` で wdired にして適当に書き換え、`ZQ` で取り消せることを確かめる。

wdired では、ファイル名の部分だけが編集できる。`cw` や `.`、マクロなど evil の操作がそのまま使える。
