# レッスン 8: シェルコマンド・圧縮・比較 (`8-shell`)

> このファイルは `setup.sh` が `tutor/dired/lessons/` からコピーしたもの。
> チェックを付けるなど書き込んでもよい (`setup.sh` を実行し直すと元に戻る)。
> 全体の説明 (始め方、キーの調べ方) は練習用ディレクトリ直下の `00-README.md` にある。

| キー | 動作 |
|---|---|
| `!` | 印の付いたファイル (なければカーソル行) にシェルコマンドを実行する |
| `&` | `!` の非同期版 (Emacs が固まらない) |
| `c` | 印の付いたファイルを 1 つのアーカイブにまとめる (拡張子で形式が決まる) |
| `Z` | 1 つずつ圧縮 / 展開する |
| `=` | カーソル行のファイルと、入力したファイルの差分を見る |

`!` に渡すコマンドでは、`*` と `?` が特別な意味を持つ (前後に空白があるとき)。

- `*` を含む: ファイルの一覧を `*` の位置に入れて、1 回だけ実行する
- `?` を含む: ファイルごとに、名前を `?` の位置に入れて実行する
- どちらもない: ファイルごとに、名前を末尾に付けて実行する

- [ ] `log1.txt` と `log2.txt` に印を付け、`!` で `wc -l` と入力する (ファイルごとに実行される)。
- [ ] 同じ印のまま `!` で `cat * > all.txt` と入力し、1 つにまとめる。`gr` で `all.txt` ができたことを確かめる。
- [ ] `a.txt` と `b.txt` に印を付け、`c` で `fruits.tar.gz` と入力してまとめる。
- [ ] `log2.txt` で `Z` を押すと `log2.txt.gz` になる。もう一度 `Z` で戻す。
- [ ] `b.txt` の行で `=` を押し、`a.txt` を指定して差分を見る (みかん と バナナ の違い)。

重いファイルをファイルシステムをまたいで移動するときは、`R` だと Emacs が固まるので、
印を付けて `&` で `mv * /移動先/` と打つと、裏でシェルの `mv` を実行できる。
