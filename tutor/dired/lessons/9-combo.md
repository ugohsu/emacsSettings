# レッスン 9: consult・embark と組み合わせる (`9-combo`)

dired だけでは手間のかかる「あちこちのディレクトリに散らばったファイルをまとめて扱う」
「dired を開かずにファイルを操作する」といった作業を、consult と embark で補う。

| キー | 動作 |
|---|---|
| `f` → `M-e` | `consult-find` で探した結果を dired の一覧に書き出す (embark-export) |
| `SPC a` | カーソル行のファイルやディレクトリに embark のアクションを実行する |
| `SPC a` → `C r` | カーソル行のディレクトリの中だけを `consult-ripgrep` で検索する |
| `SPC a` → `y p` / `y d` / `y n` | 絶対パス / ディレクトリ / ファイル名をコピーする (自分の embark 設定) |
| `M-a` | ミニバッファの補完中に、選択中の候補に embark のアクションを実行する |
| `M-a` → `j` | 候補のファイルの場所を dired で開き、その行にカーソルを置く |
| `M-a` → `r` / `d` | 候補のファイルの名前を変える / 消す (dired を開かずに) |

## 散らばったファイルを集める

- [ ] `9-combo` で `f` を押し、`csv` と入力する。`2024/jan`、`2024/feb`、`2025/mar` にある 3 つの CSV が候補に出る。
- [ ] そのまま `M-e` を押す。3 つの CSV だけが並んだ dired (`*Embark Export Dired ...*`) が開く。
- [ ] この一覧は普通の dired として使える。`t` で全部に印を付け、`R` で `collected/` に移動する
      (送り先の入力欄の末尾に `collected/` を足して `RET`)。

`collected` に `sales-2024-01.csv`、`sales-2024-02.csv`、`sales-2025-03.csv` が入れば成功。

## 散らばった一時ファイルを消す

- [ ] `9-combo` で `f` → `tmp` → `M-e` と押し、`.tmp` のファイル 3 つだけの dired を作る。
- [ ] `t` で全部に印を付けて `D` で消す (`% d` で `\.tmp$` → `x` でもよい)。

書き出した一覧でも、レッスン 4〜6 の操作 (`d` → `x`、`% R`、wdired など) がそのまま使える。

## ディレクトリを指定して検索・置換する

- [ ] `9-combo` の `docs` の行で `SPC a` → `C r` と押し、`締め切り` と入力する。
      `docs` の中の 2 ファイルだけが出て、`2024/feb/notes.md` は出ない。
- [ ] そのまま `M-e` で grep の一覧に書き出し、`C-c C-p` で編集できる状態 (wgrep) にする。
      2 か所の `締め切り` を `〆切` に書き換え、`C-c C-c` で各ファイルに反映する。
      最後に `M-x save-some-buffers` (`!` で全部) で保存する。

レッスン 7 の `Q` は印を付けたファイルが対象だったが、こちらは「このディレクトリの下全部」が対象になる。
結果を見ながら手で直したいときは、こちらのほうが向いている。

## dired を開かずにファイルを操作する

- [ ] `SPC f` (find-file) で `9-combo/docs/` まで入力し、候補の `faq.md` を選んだ状態で `M-a` → `j` を押す。
      `docs` の dired が開き、`faq.md` の行にカーソルが来る。
- [ ] もう一度 `SPC f` で `faq.md` を選び、`M-a` → `r` で `faq-old.md` に名前を変える。
- [ ] `SPC b` で最近開いたファイル (例: `guide.md`) を選んだ状態で `M-a` → `j` を押し、その場所の dired を開く。

`M-a` → `j` (embark-dired-jump) は、「今のファイルの場所を dired で開く」`C-x C-j` (dired-jump。
この設定では SKK に使っている) の代わりになる。

## よく行くディレクトリをブックマークする

- [ ] `9-combo` の dired で `C-x r m` を押し、`tutor` という名前でブックマークする。`q` で dired を閉じる。
- [ ] `SPC b` で `m SPC` と打つと、候補がブックマークだけに絞られる。`tutor` を選ぶと `9-combo` の dired が開く。
- [ ] 練習が終わったら `M-x bookmark-delete` で `tutor` を消す (ブックマークは Emacs を終了しても残るため)。
