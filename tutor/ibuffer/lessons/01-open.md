# レッスン 1: 開く・動く・切り替える

ibuffer は、開いているバッファの一覧。dired がファイルを一覧して操作するように、
ibuffer はバッファを一覧して、開く・保存する・消すなどの操作をまとめて行う。
`SPC b` (consult-buffer) が「1 つ選んで開く」ためのものなのに対して、
ibuffer は「たくさんのバッファを見渡して整理する」ためのもの。

| キー | 動作 |
|---|---|
| `SPC B` (`C-x C-b`) | ibuffer を開く (開くたびに一覧が最新になる) |
| `j` / `k` | 上下に動く |
| `gj` / `gk` | 次 / 前のバッファの行へ (見出しの行を飛ばし、端まで行くと反対の端に戻る) |
| `J` (`M-g`) | バッファ名を入力して、その行に飛ぶ |
| `RET` | カーソル行のバッファを、このウィンドウで開く |
| `go` | 別のウィンドウで開き、そちらに移る |
| `gO` | 別のウィンドウに出すだけで、ibuffer に留まる |
| `M-o` | このウィンドウで開き、ほかのウィンドウを閉じる |
| `C-x C-f` | カーソル行のバッファのディレクトリを起点に、ファイルを開く |
| `X` | カーソル行のバッファを、バッファの順番の一番後ろに回す (bury。`SPC b` の候補で下のほうに出る) |
| `gr` | 一覧を作り直す (ibuffer を開いたあとで増えた・消えたバッファを反映する) |
| `C-c C-a` | 一覧の自動更新 (ibuffer-auto-mode) を切り替える |
| `q` | ibuffer を閉じる |

- [ ] 右のウィンドウで `SPC B` を押して ibuffer を開く。`j` / `k` で動き、`gj` を何度も押して、
      一番下まで行くと一番上のバッファに戻ることを確かめる。
- [ ] `J` を押し、`memo` と入力して `memo.txt` を選ぶ。その行にカーソルが飛ぶ。`RET` で開き、`SPC B` で戻る。
- [ ] `utils.py` の行で `gO` を押す。左のウィンドウに `utils.py` が出て、カーソルは ibuffer に残る。
      左を元に戻すには、`SPC h` で左に移り、`SPC b` で `00-tutor.md` を選ぶ。`SPC l` で右に戻る。
- [ ] `plot.R` の行で `go` を押す。左のウィンドウに `plot.R` が出て、カーソルもそちらに移る。
      `SPC b` で `00-tutor.md` に戻し、`SPC l` で右に移って `SPC B`。
- [ ] `todo.org` の行で `M-o` を押す。画面が `todo.org` だけになる。
      `SPC 3` で左右に分け直し、左で `SPC b` → `00-tutor.md`、右 (`SPC l`) で `SPC B` に戻す。
- [ ] `analysis.R` の行で `C-x C-f` を押す。入力欄が `~/ibuffer-tutor/projB/` から始まる。
      `new.R` と入力して開き (まだ保存しない)、`SPC B` で戻ると、一覧に `new.R` が増えている。
- [ ] ibuffer にいるまま `<f1> f` → `ibuffer` → `RET` で関数の説明を開く (`*Help*` が左に出て、カーソルは右に残る)。
      一覧にはまだ `*Help*` がない。`gr` を押すと現れる。左は `SPC h` → `SPC b` → `00-tutor.md` で戻す。
- [ ] `C-c C-a` を押すと、モードライン (画面下の帯) に `(Auto)` と出る。この間は `gr` を押さなくても一覧が更新される。
      もう一度 `C-c C-a` で戻す。
- [ ] `memo.txt` の行で `X` を押す。`SPC b` を押すと、`memo.txt` が候補の下のほうに回っている (`C-g` で閉じる)。
      もう使わないが消したくないバッファを、候補の上から外すのに使う。
- [ ] `q` で ibuffer を閉じ、`SPC B` で開き直す。
