# レッスン 2: 一覧の見方・並べ替え

一覧の左端の 4 文字は、バッファの状態を表す。

| 列 | 意味 |
|---|---|
| 1 文字目 | 印 (`>` は選んだ、`D` は消す予定。レッスン 3・5) |
| `M` の列 | `*` なら変更があって、まだ保存していない |
| `R` の列 | `%` なら読み取り専用 |
| `L` の列 | ロックされている (この設定では使わない) |

続いて、バッファ名 (`Name`)・大きさ (`Size`、文字数)・メジャーモード (`Mode`)・ファイル名 (`Filename/Process`) が並ぶ。
今の並べ方と絞り込みの条件は、モードライン (画面下の帯) に `Ibuffer by recency` のように出る。

| キー | 動作 |
|---|---|
| `,` | 並べ方を順に切り替える (名前 → ファイル名 → メジャーモード → モード名 → 最近表示した順 → 大きさ) |
| `o v` | 最近表示した順 (初期設定) |
| `o a` | バッファ名の順 |
| `o f` | ファイル名 (またはプロセス名) の順 |
| `o m` | メジャーモードの順 |
| `o s` | 大きさの順 |
| `o i` | 今の並べ方を逆順にする / 戻す (モードラインに `[rev]` と出る) |
| `` ` `` | 表示形式を切り替える (すべての列 ↔ 名前とファイル名だけ) |
| `gR` | 表示し直す (中身は作り直さない。`gr` は一覧を作り直す) |

- [ ] モードラインに `by recency` と出ていることを確かめる。`o a` で名前の順にし、モードラインが `by alphabetic` に変わるのを見る。
- [ ] `README.md<projA>` と `README.md<projB>` があることを確かめる。同じ名前のファイルを 2 つ開くと、
      Emacs はディレクトリ名を `<…>` で付けて区別する (uniquify)。
- [ ] `o s` で大きさの順にする。小さい順なので、`big.log` が一番下に来る。`o i` で逆順にして、`big.log` を一番上にする。
      もう一度 `o i` で戻す。
- [ ] `o m` でメジャーモードの順にし、`Python` や `ESS[R]` のバッファがまとまって並ぶのを見る。
- [ ] `o f` でファイル名の順にし、`projA`・`projB`・`notes` ごとにまとまるのを見る。
      ファイルのないバッファ (`*scratch*` など) は、ファイル名の列が空になる。
- [ ] `,` を何度か押して、並べ方がモードラインで順に変わるのを見る。最後に `o v` で最近表示した順に戻す。
- [ ] `` ` `` で名前とファイル名だけの表示にし、もう一度 `` ` `` で戻す。
- [ ] `R` の列に `%` が付いているバッファを探す。`readonly.txt` (書き込みできないファイル) や `*Messages*`、閲覧用表示の `00-tutor.md` に付いている。
