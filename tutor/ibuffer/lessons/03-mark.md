# レッスン 3: 印を付ける

`m` で付ける印は `>` で (dired の `*` にあたる)、「選んだ」という意味しか持たない。
何をするかは後で大文字のキー (`S` 保存、`D` 消す、`A` 並べて表示など) で決める。
印がないときは、たいていカーソル行のバッファだけが対象になる。

| キー | 動作 |
|---|---|
| `m` / `u` | 印を付ける / 外す (付けたら次の行へ進む) |
| `DEL` | 1 つ上の行の印を外して、上に戻る |
| `U` | すべての印を外す |
| `M-DEL` | 種類を指定して印を外す (`>` なら `>` だけ、`RET` ならすべて) |
| `t` (`~`) | 印を反転する |
| `* c` | 印の種類を変える (`* c` → 元の印 → 新しい印。例: `* c > 1` で `>` を `1` に) |
| `}` / `{` | 次 / 前の印の付いた行へ (`M-}` / `M-{` でもよい) |
| `yb` | 印の付いたバッファ (なければカーソル行) の名前をコピーする (レッスン 12) |
| `A` (`gv`) | 印の付いたバッファを、画面を分けて並べて表示する |
| `gV` | 同じく、左右に並べて表示する |

`V` は evil のビジュアル行選択ではなく、素の ibuffer と同じ「印の付いたバッファをファイルから読み直す」(レッスン 6) になっている。
範囲を選んで印を付ける使い方はできないので、`m` を続けて押すか、レッスン 4 の条件で付ける。

- [ ] `main.py`・`utils.py`・`run.sh` に `m` で印を付ける。`u` で 1 つ外し、`DEL` で 1 つ前の行に戻りながら外す。`U` で全部外す。
- [ ] `memo.txt` と `todo.org` に印を付け、`}` と `{` で印の行を行き来する。
- [ ] そのまま `t` を押して、印を反転する (ほかのバッファすべてに印が付く)。`U` で外す。
- [ ] `main.py` と `analysis.R` に印を付けて `A` を押す。画面が分かれ、2 つが上下に並ぶ。
      見終わったら `SPC 1` → `SPC 3` で分け直し、左に `00-tutor.md`、右に ibuffer (`SPC B`) を戻す。
      (印は残っているので、`U` で外す)

## 印を退避する: 2 つの選び方を同時に持つ

印の文字は `>` だけでなく、好きな 1 文字を使える。操作のキーが対象にするのは `>` の印だけなので、
ほかの文字に変えておけば、その選び方を残したまま、別のバッファを `>` で選んで操作できる (dired の `* c` と同じ)。

- [ ] `memo.txt` と `todo.org` に印を付けて `* c` を押す。`Change (old mark):` と聞かれたら、変える前の印 `>` を押し、
      `Change > marks to (new mark):` と聞かれたら、新しい印 `1` を押す。2 つの印が `1` に変わる。
- [ ] `main.py` に `m` で印を付けて `yb` を押す。エコーエリアに `main.py` とだけ出る (`1` の印のバッファは対象にならない)。
- [ ] `M-DEL` を押し、`Remove marks (RET means all):` と聞かれたら `>` を押す。`>` の印だけが外れ、`1` は残る
      (`U` だとすべての印が外れる)。
- [ ] `* c` → `1` → `>` で、`memo.txt` と `todo.org` の印を `>` に戻す。`U` で外す。
