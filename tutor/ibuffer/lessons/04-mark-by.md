# レッスン 4: 条件で印を付ける

1 つずつ `m` で選ぶ代わりに、モード・名前・中身・状態などの条件でまとめて印を付ける。
付けた印はレッスン 3 と同じように `U` で外せる。各課題の終わりに `U` で外しておく。

| キー | 印を付けるバッファ |
|---|---|
| `* M` | 指定したメジャーモードのもの (補完で選ぶ。初期値はカーソル行のモード) |
| `% m` | モード名 (一覧の `Mode` 列) が正規表現に一致するもの |
| `% n` | バッファ名が正規表現に一致するもの |
| `% f` | ファイル名 (`~/` から始まるパス) が正規表現に一致するもの |
| `% g` | 中身が正規表現に一致するもの |
| `* m` | 変更があるもの (ファイルのないバッファも含む) |
| `* u` | 変更があって、まだ保存していないファイル |
| `* r` | 読み取り専用のもの |
| `* s` (`* *`) | 名前が `*` で始まって `*` で終わるもの (`*scratch*` などの特殊バッファ) |
| `* h` | ヘルプのバッファ (`*Help*` など) |
| `* /` | dired のバッファ |
| `* z` | 圧縮されたファイル (`.gz` など) |
| `* e` | 開いたあとで、元のファイルが消えたもの |
| `.` | 3 日以上表示していないもの (練習では印が付かない) |

- [ ] `main.py` の行で `* M` を押す。初期値が `python-mode` なので、そのまま `RET` で Python のバッファ 2 つに印が付く。`U` で外す。
- [ ] `% m` で `Python\|ESS` と入力して、Python と R のバッファに印を付ける。`U` で外す。
- [ ] `% n` で `^README` と入力して、`README.md<projA>` と `README.md<projB>` に印を付ける。`U` で外す。
- [ ] `% f` で `projB` と入力して、`projB` の中のファイルに印を付ける。`U` で外す。
- [ ] `% g` で `old_name` と入力して、中身に `old_name` があるバッファに印を付ける。`00-tutor.md` にも付く
      (この課題の文字列が書いてあるため)。`U` で外す。
- [ ] `* s` で特殊バッファに印を付ける。`*scratch*` や `*Messages*` に付く。`U` で外す。
- [ ] `* r` で読み取り専用のバッファに印を付ける。`readonly.txt` と `00-tutor.md` (閲覧用表示)、特殊バッファのいくつかに付く。`U` で外す。
- [ ] `* z` で `archive.txt.gz` に印を付ける。中身は展開して表示されているが、ファイルは圧縮されたまま。`U` で外す。
- [ ] `memo.txt` を開き (`RET`)、`i` で何か書いて `ESC` で戻る (保存しない)。`SPC B` で戻り、`* u` で `memo.txt` に印を付ける。
      `*scratch*` に何か書いてから `* m` を押すと、`*scratch*` にも付く (ファイルがないので `* u` では付かない)。
      `U` で外す。書いた内容はレッスン 6 で扱うので、そのまま残しておく。
- [ ] `<f1> f` → `ibuffer` → `RET` でヘルプを開き、`gr` のあとで `* h` を押して `*Help*` に印を付ける。`U` で外す。
      (左のウィンドウは `SPC h` → `SPC b` → `00-tutor.md` で戻す)
- [ ] `SPC d` → `RET` で dired を開き (開くディレクトリはどこでもよい)、`SPC B` で ibuffer に戻って `* /` で dired のバッファに印を付ける。`U` で外す。
- [ ] `M-!` (shell-command) で `rm ~/ibuffer-tutor/notes/delete-me.txt` と入力してファイルだけを消す。
      `gr` のあとで `* e` を押すと、`delete-me.txt` に印が付く (バッファは残っている)。`U` で外す。

`% g` は、dired などのバッファや `*Messages*` などは調べない。
すべてのバッファを調べるときは `C-u % g` にする。
