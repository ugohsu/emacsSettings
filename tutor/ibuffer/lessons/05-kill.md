# レッスン 5: バッファを消す・一覧から隠す

「バッファを消す」(kill) は、Emacs の中で開いているものを閉じること。ファイルは消えない。
変更を保存していないバッファを消すときは、保存せずに消してよいか確認される。

「一覧から隠す」は、ibuffer の表示から外すだけで、バッファはそのまま残る。

| キー | 動作 |
|---|---|
| `d` | 消す予定の印 `D` を付ける |
| `x` | `D` の印の付いたバッファを消す |
| `D` | `*` の印の付いたバッファ (なければカーソル行) を、確認してすぐに消す |
| `K` | `*` の印の付いた行を、一覧から隠す (`gr` で戻る) |
| `-` | 正規表現に一致する名前のバッファを、この ibuffer では表示しない (`gr` のあとで効く) |
| `+` | 正規表現に一致する名前のバッファを、絞り込みに関係なく必ず表示する (`gr` のあとで効く) |

- [ ] `*Help*` の行で `d` を押し、`D` の印を付ける (レッスン 4 で `*Help*` を開いていなければ、`<f1> f` → `ibuffer` → `RET` で開いて `gr`)。
      `x` で消す。確認に `y` で答える。
- [ ] `delete-me.txt` (レッスン 4 でファイルを消したもの) と `sample.el` に `m` で印を付け、`D` で消す。
- [ ] 印を付けずに `new.R` (レッスン 1 で作ったもの) の行で `D` を押して消す。
- [ ] `big.log` と `archive.txt.gz` に `m` で印を付けて `K` を押す。2 つが一覧から消えるが、`SPC b` の候補には残っている。
      `gr` で一覧に戻る。
- [ ] `*Messages*` の行で `-` を押す。入力欄に `\*Messages\*` が入っているので、そのまま `RET`。`gr` を押すと一覧から消える。
      この設定は `*Ibuffer*` を消すまで残る。元に戻すには、`M-x kill-current-buffer` で ibuffer を閉じて `SPC B` で開き直す。
- [ ] `-` で `^\*` と入力し、`gr` で特殊バッファをすべて隠す。続けて `+` で `^\*scratch\*$` と入力し、`gr` で `*scratch*` だけを表示する
      (`+` は `-` より優先される)。`M-x kill-current-buffer` → `SPC B` で元に戻す。

消したバッファを開き直すには、`SPC b` で最近開いたファイルとして選ぶか、`SPC f` で開く。
練習用のバッファをまとめて元に戻したいときは、Emacs を終了して開き直す。
