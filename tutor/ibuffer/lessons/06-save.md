# レッスン 6: 保存・読み直し・差分

ファイルを開いたバッファは、編集しても保存するまではファイルに書き込まれない。
ibuffer では、変更のあるバッファを探して、まとめて保存したり、変更を捨てたりできる。

| キー | 動作 |
|---|---|
| `=` | 印の付いたバッファ (なければカーソル行) と、元のファイルとの差分を表示する |
| `S` | 印の付いたバッファを保存する |
| `V` | 印の付いたバッファを、ファイルから読み直す (変更を捨てる。確認あり) |
| `M` | 「変更あり」の状態 (`M` の列の `*`) を切り替える (中身は変わらない) |
| `T` | 読み取り専用を切り替える (`R` の列の `%`) |
| `R` | バッファ名を、ほかと重ならない名前 (`<2>` などを付けたもの) に変える |

レッスン 4 で `memo.txt` と `*scratch*` に書き込んでいなければ、先にそれぞれ何か書いておく。

- [ ] `memo.txt` の行で `=` を押す。`*Ibuffer Diff*` に差分が出る。`SPC B` で ibuffer に戻る。
- [ ] `main.py` と `plot.R` を開いて、それぞれ 1 行書き足す (保存しない)。ibuffer に戻ると、`M` の列に `*` が付いている。
- [ ] `* u` で未保存のファイルに印を付け、`=` で 3 つまとめて差分を見る。
- [ ] `plot.R` の印だけを外し (`u`)、残りの `memo.txt` と `main.py` を `S` で保存する。`M` の列の `*` が消える。
- [ ] `plot.R` の行で `V` を押し、`y` で答えて、書き足した行を捨てる。
- [ ] `*scratch*` の行で `M` を押して、「変更あり」の印を消す (書いた内容は残る)。
      ファイルのないバッファは保存できないので、`* m` → `S` などで引っかからないようにするときに使う。
- [ ] `todo.org` の行で `T` を押して読み取り専用にする (`R` の列に `%`)。開いて書き込もうとすると拒まれる。もう一度 `T` で戻す。
- [ ] `*scratch*` の行で `R` を押す。名前が `*scratch*<2>` になる。`M-x eshell` のように、同じ名前のバッファがあると
      そこに切り替わるだけのコマンドで、今のバッファを残したまま、もう 1 つ新しく開きたいときに使う。

`memo.txt` と `main.py` は保存して書き換わったので、最初の状態に戻すには `setup.sh` を実行し直す
(レッスン 10・11 の課題は、書き換わったままでもできる)。
