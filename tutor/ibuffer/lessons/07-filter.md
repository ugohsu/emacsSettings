# レッスン 7: 絞り込み

絞り込み (filter) は、条件に合うバッファだけを一覧に出す。印とは違い、操作の対象を選ぶのではなく、
見る範囲を狭める。絞り込んだまま `t` (印の反転) や `m` を使うと、見えているバッファだけが対象になる。

絞り込みを重ねると「かつ」(AND) になる。今の条件はモードライン (画面下の帯) に `[major mode in use: python-mode]` のように出る
(条件が長くなると、画面上の帯に出る)。

| キー | 絞り込みの条件 |
|---|---|
| `s m` | 使われているメジャーモードから選ぶ (`,` で区切って複数選べる) |
| `s RET` | すべてのメジャーモードから選ぶ (初期値はカーソル行のモード) |
| `s M` | 派生元のモード (例: `prog-mode` でプログラムのモードすべて、`text-mode` で文章のモードすべて) |
| `s n` | バッファ名 (正規表現) |
| `s *` | 名前が `*` で始まって `*` で終わる (特殊バッファ) |
| `s f` | ファイル名 (フルパス。正規表現) |
| `s b` | ファイル名 (ディレクトリを除いた部分。正規表現) |
| `s .` | 拡張子 (`.` を除く。正規表現) |
| `s >` / `s <` | 大きさ (文字数) がより大きい / より小さい |
| `s i` | 変更がある |
| `s v` | ファイルを開いている (ファイルのないバッファを除く) |
| `s c` | 中身 (正規表現) |
| `s e` | Lisp の式 (各バッファの中で評価して、`nil` 以外ならば残す) |
| `s p` | 最後に加えた条件を外す |
| `s /` | すべての条件を外す |

- [ ] `s m` で `python-mode` を選ぶ。Python のバッファだけになる。モードラインの条件を確かめて、`s /` で外す。
- [ ] `s M` で `prog-mode` を選ぶ。Python・R・シェルスクリプト・Emacs Lisp のバッファと `*scratch*` が残る
      (R の ESS のモードも、`*scratch*` の lisp-interaction-mode も `prog-mode` から派生している)。`s /` で外す。
- [ ] `s M` で `text-mode` を選ぶ。Markdown・Org・テキストのバッファが残る。`s /` で外す。
- [ ] `s f` で `projA` と入力して `projA` の中だけにする。続けて `s .` で `py` と入力すると、`projA` の Python ファイルだけになる
      (2 つの条件の「かつ」)。`s p` で最後の条件だけを外し、`s /` ですべて外す。
- [ ] `s b` で `^README` と入力する。`README.md<projA>` と `README.md<projB>` が残る。
      `s n` でも同じことができるが、`s b` はバッファ名ではなくファイル名で調べる。`s /` で外す。
- [ ] `s *` で特殊バッファだけにする。`s /` で外す。続けて `s v` でファイルのあるバッファだけにする。`s /` で外す。
- [ ] `s >` で `10000` と入力して、大きいバッファ (`big.log` など) だけにする。`s /` で外す。
- [ ] `s c` で `TODO` と入力して、中身に TODO があるバッファだけにする (`00-tutor.md` も残る)。`s /` で外す。
- [ ] `main.py` に何か書き足してから ibuffer に戻り、`s i` で変更のあるバッファだけにする。`s /` で外す
      (書き足した内容は、`main.py` の行で `V` → `y` で捨てる)。
- [ ] `s e` で `buffer-read-only` と入力して、読み取り専用のバッファだけにする。`s /` で外す。
- [ ] `s .` で `py` と入力して絞り込んだまま `t` を押す。見えている Python のファイル 2 つだけに印が付く。`U` で外し、`s /` で外す。
