# レッスン 8: 絞り込みを組み合わせる・保存する

絞り込みの条件は、上に積み重なっていく (スタック)。積んだ条件は、上から順に「または」でまとめたり、
否定したり、入れ替えたりできる。よく使う組み合わせには名前を付けて保存できる。

| キー | 動作 |
|---|---|
| `s \|` (`s o`) | 上の 2 つの条件を「または」(OR) でまとめる |
| `s &` | 上の 2 つの条件を「かつ」(AND) でまとめる (`s \|` でまとめたものの中で使う) |
| `s !` | 一番上の条件を否定する (「〜でない」にする) |
| `s t` (`s TAB`) | 上の 2 つの条件を入れ替える |
| `s d` | 一番上の「または」「否定」「保存した条件」を、元の条件に分解する |
| `s r` | 保存した条件に切り替える (今の条件は外れる) |
| `s a` | 保存した条件を、今の条件に加える |
| `s s` | 今の条件に名前を付けて保存する (`~/.emacs.d/custom.el` に書き込む) |
| `s x` | 保存した条件を消す (`~/.emacs.d/custom.el` からも消える) |

- [ ] `s .` で `py` → `s .` で `^R$` と入力する。「かつ」なので、何も残らない。`s |` を押すと「または」になり、
      Python と R のファイルが残る。モードラインの条件が `[OR ...]` の形に変わるのを見る。
      (`^` と `$` を付けないと、大文字小文字を区別しないので、`org` などの `r` を含む拡張子にも一致する)
- [ ] そのまま `s !` を押す。「Python でも R でもない」バッファが残る。`s !` をもう一度押すと元に戻る。
- [ ] `s d` で「または」を 2 つの条件に分解する (また何も残らなくなる)。`s /` で外す。
- [ ] `s *` → `s !` で、特殊バッファを除いた一覧にする。日常的にはこの絞り込みが便利。`s /` で外す。
- [ ] `s f` で `proj` → `s .` で `md` と入力する。`proj` の中の Markdown (README 2 つ) が残る。
      ここで `s !` を押すと、一番上の条件 (`md`) が否定されて「`proj` の中の、Markdown でない」ファイルになる。`s !` で戻す。
- [ ] 続けて `s t` で 2 つの条件を入れ替える (モードラインの順が変わる)。ここで `s !` を押すと、今度は `proj` が否定されて
      「`proj` の外の Markdown」、つまり `00-tutor.md` だけが残る。`s /` で外す。
- [ ] 保存済みの条件を使う。`s r` で `programming` を選ぶと、プログラムのバッファだけになる。
      `s r` で `text document` を選ぶと、文章のバッファ (特殊バッファを除く) になる。`s /` で外す。
      (この 2 つは Emacs に最初から入っている)
- [ ] `s r` で `programming` → `s f` で `projA` と入力したあと、`s s` で `tutor-projA-code` と名前を付けて保存する。
      `s /` で外し、`s r` → `tutor-projA-code` で同じ絞り込みに戻れることを確かめる。
- [ ] `s /` で外し、`s f` で `projB` → `s a` → `tutor-projA-code` と押す。保存した条件が今の条件に「かつ」で加わる
      (`projB` かつ `projA` なので、何も残らない)。`s /` で外す。
- [ ] 後片付け: `s x` で `tutor-projA-code` を選んで消す。

`~/.emacs.d/custom.el` に保存される変数は `ibuffer-saved-filters`。
保存した条件は Emacs を再起動しても残るので、練習で作ったものは必ず `s x` で消す。
