# レッスン 9: フィルタグループ

フィルタグループは、一覧を見出し付きのグループに分ける。絞り込みと同じ条件で作り、
どのグループの条件にも合わないバッファは、最後の `[ Default ]` グループに入る。
バッファは、上にあるグループから順に調べて、最初に合ったグループにだけ入る。

| キー | 動作 |
|---|---|
| `s g` | 今の絞り込みの条件を、名前を付けてグループにする (絞り込みは外れる) |
| `TAB` / `S-TAB` | 次 / 前のグループの見出しへ (`M-n` / `M-p` でもよい) |
| `M-j` | グループ名を入力して、その見出しへ飛ぶ |
| `RET` (見出しの行で) | そのグループを畳む / 開く |
| `m` / `u` / `t` (見出しの行で) | そのグループのバッファすべてに印を付ける / 外す / 反転する |
| `gx` (見出しの行で) | そのグループを切り取る |
| `C-y` | 切り取ったグループを、カーソルのあるグループの前に貼り付ける (並べ替え) |
| `s P` | 一番上のグループを外す |
| `s D` | 指定したグループを外して、その条件を絞り込みにする |
| `s \` | すべてのグループを外す |
| `M-x ibuffer-set-filter-groups-by-mode` | メジャーモードごとにグループを作る |
| `s S` | 今のグループに名前を付けて保存する (`~/.emacs.d/custom.el` に書き込む) |
| `s R` | 保存したグループに切り替える |
| `s X` | 保存したグループを消す |

- [ ] `s f` で `projA` → `s g` で `projA` と名前を付ける。続けて `s f` で `projB` → `s g` → `projB`、
      `s f` で `notes` → `s g` → `notes` と作る。一覧が `[ notes ]`・`[ projB ]`・`[ projA ]`・`[ Default ]` に分かれる
      (後から作ったグループが上に来る)。
- [ ] `TAB` と `S-TAB` で見出しを行き来する。`M-j` で `projB` と入力して、その見出しへ飛ぶ。
- [ ] `[ Default ]` の見出しで `RET` を押して畳む (特殊バッファなどが隠れる)。もう一度 `RET` で開く。
- [ ] `[ projA ]` の見出しで `m` を押して、`projA` のバッファすべてに印を付ける。`U` で外す。
- [ ] `[ projA ]` の見出しで `gx` を押してグループを切り取り、`[ notes ]` の見出しに移って `C-y` で貼り付ける。
      `projA` が一番上に来る。
- [ ] `s P` で一番上のグループ (`projA`) を外す。`projA` のバッファは `[ Default ]` に入る。
- [ ] `s \` ですべてのグループを外す。
- [ ] `M-x ibuffer-set-filter-groups-by-mode` で、メジャーモードごとのグループを作る。`s \` で外す。
- [ ] もう一度 `projA`・`projB`・`notes` のグループを作り、`s S` で `tutor-projects` と名前を付けて保存する。
      `s \` で外し、`s R` → `tutor-projects` で戻れることを確かめる。
- [ ] `s D` で `projB` を選ぶ。`projB` のグループが外れ、その条件 (`projB` のファイル名) が絞り込みになる。`s /` と `s \` で外す。
- [ ] 後片付け: `s X` で `tutor-projects` を選んで消す。

`~/.emacs.d/custom.el` に保存される変数は `ibuffer-saved-filter-groups`。
いつも同じグループで開きたいときは、`init.el` に `ibuffer-saved-filter-groups` を書き、
`ibuffer-hook` で `(ibuffer-switch-to-saved-filter-groups "名前")` を呼ぶのが定番の設定。
