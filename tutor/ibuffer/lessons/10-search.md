# レッスン 10: 複数のバッファを検索・置換する

印の付いたバッファをまとめて検索・置換する。ファイルに対する一括置換 (dired の `Q` や consult-ripgrep + wgrep) と違い、
開いているバッファ (保存していない変更や、ファイルのないバッファも含む) が対象になる。
置換したあとは保存するまでファイルは変わらないので、`=` で差分を見てから `S` で保存できる。

| キー | 動作 |
|---|---|
| `O` | 印の付いたバッファで、正規表現に一致する行を `*Occur*` に一覧する (`RET` でその行へ) |
| `M-s a C-s` | 印の付いたバッファをまたいで isearch する (`C-s` で次へ。バッファの終わりまで来ると次のバッファへ) |
| `M-s a C-M-s` | 同じく、正規表現で isearch する |
| `Q` | 印の付いたバッファで、1 つずつ確認しながら置換する (query-replace) |
| `I` | 同じく、正規表現で確認しながら置換する |
| `r` | 印の付いたバッファで、確認せずに正規表現で置換する |

置換するときは、`00-tutor.md` に印を付けないように注意する (課題の文字列も置換されてしまう)。
ここでは `% f proj` で `projA`・`projB` のファイルだけに印を付けて使う。

- [ ] `% f` で `proj` と入力して印を付け、`O` で `TODO` と入力する。別のウィンドウに `*Occur*` が出て、各ファイルの TODO の行が並ぶ。
      `*Occur*` のウィンドウに移り (`SPC h` など)、`j` / `k` で行を選んで `RET` を押すと、その行に飛ぶ。
      終わったら、左に `00-tutor.md`、右に ibuffer (`SPC B`) を戻す (印は残っている)。
- [ ] そのまま `M-s a C-s` を押して `old_name` と入力する。`C-s` を押すたびに次の `old_name` に移り、
      バッファの終わりまで来ると次のバッファに移る。`RET` で検索を終える。`SPC B` で戻る。
- [ ] そのまま `Q` を押し、`old_name` → `old_value` と入力する。1 つずつ確認されるので、`y` で置換、`n` で飛ばす
      (`!` でそのバッファの残りをすべて置換)。全部終わったら ibuffer に戻る。
- [ ] `U` で印を外してから `* u` で変更のあるファイルに印を付け直し、`=` で差分を確かめる。`SPC B` で戻り、`V` → `y` で置換を取り消す。
- [ ] `% f` で `proj` と入力して印を付け直し、`r` を押して `old_\(name\)` → `new_\1` と入力する。確認なしで `new_name` に置換される。
      `=` で差分を確かめてから、`V` → `y` で取り消す (保存するなら `S`)。
- [ ] `% f` で `proj` と入力して印を付け、`I` で `^# TODO` → `# DONE` と入力する。行頭の `# TODO` (Python と R のコメント) だけが対象になり、
      `README.md<projA>` の文中の TODO は対象にならない。`y` で置換して、`=` で差分を見てから `V` → `y` で取り消す。`U` で印を外す。

`O` の結果の `*Occur*` では、`i` を押すと編集できる (occur-edit-mode。evil-collection の割り当て)。
編集が元のバッファにそのまま反映されるので、行を見ながら直すのにも使える。`ESC` (または `C-c C-c`) で編集を終える。
