# レッスン 11: 複数のバッファでコマンドや式を実行する

印の付いたバッファそれぞれで、シェルコマンドや Emacs Lisp の式を実行する。
シェルコマンドの出力は `*Shell Command Output*` に溜まる (バッファごとの出力が続けて並ぶ)。
自動では表示されないので、`SPC b` で `*Shell Command Output*` を選んで見る。

| キー | 動作 |
|---|---|
| `\|` | バッファの中身をシェルコマンドに渡して、出力を `*Shell Command Output*` に出す (バッファは変わらない) |
| `!` (`F`) | バッファのファイル名を後ろに付けてシェルコマンドを実行し、出力を `*Shell Command Output*` に出す |
| `N` | バッファの中身をシェルコマンドに渡して、出力で中身を置き換える (確認あり) |
| `E` | Lisp の式を、各バッファの中で評価する |
| `W` | 同じく、各バッファを表示しながら評価する (ウィンドウが必要な処理のため) |

`!` は、変更があって保存していないバッファでは、ファイルではなく一時ファイルに書き出した中身に対して実行する。

- [ ] `main.py`・`analysis.R`・`big.log` に印を付けて `|` を押し、`wc -l` と入力する。
      `SPC b` で `*Shell Command Output*` を開くと、それぞれの行数が並んでいる。`SPC B` で戻って、`U` で印を外す。
- [ ] `% f` で `proj` と入力して印を付け、`!` で `ls -l` と入力する。`*Shell Command Output*` に各ファイルの `ls -l` の結果が並ぶ。`U` で外す。
- [ ] `memo.txt` に印を付けて `N` を押し、`sort` と入力する。確認に `y` で答えると、`memo.txt` の中身が並べ替わる。
      開いて確かめたら、ibuffer に戻って `V` → `y` で元に戻す。`U` で外す。
- [ ] `main.py` の行末には空白が残っている (開いて `$` で行末に行くとわかる)。`% f` で `proj` と入力して印を付け、
      `E` で `(delete-trailing-whitespace)` と入力する。行末の空白があったバッファだけが変更される。
      `U` で印を外してから `* u` を押すと、`main.py` にだけ印が付く。`=` で差分を見て、`V` → `y` で取り消す。`U` で外す。
- [ ] `% f` で `proj` と入力して印を付け、`E` で `(setq-local fill-column 60)` と入力する。
      バッファごとの設定 (バッファローカル変数) を、まとめて変えられる。`U` で外す。
- [ ] `% f` で `proj` と入力して印を付け、`E` で `(message "%s: %d 行" (buffer-name) (count-lines (point-min) (point-max)))` と入力する。
      エコーエリアには ibuffer の完了の知らせしか出ないが、`SPC b` で `*Messages*` を開くと、すべてのバッファの行数が並んでいる。`U` で外す。

式は `M-:` (eval-expression) と同じ書き方で入力する。`E` は、`(whitespace-cleanup)` や `(untabify (point-min) (point-max))` のように、
ibuffer にキーのないコマンドを、印の付いたバッファでまとめて実行するのにも使える。
