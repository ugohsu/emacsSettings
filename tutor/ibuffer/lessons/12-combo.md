# レッスン 12: consult・embark・dired と組み合わせる

| キー | 動作 |
|---|---|
| `SPC b` → `b SPC` | consult-buffer の候補をバッファだけに絞る (最近開いたファイルなどを除く) |
| `SPC b` → `* SPC` | consult-buffer の候補を、変更があって保存していないバッファだけに絞る |
| `SPC b` で絞り込み → `M-e` | 候補のバッファだけを並べた ibuffer (`*Embark Export Ibuffer*`) を作る (embark-export) |
| `SPC b` で選んで `M-a` → `k` | ibuffer を開かずに、そのバッファを消す |
| `yb` / `yf` | 印の付いたバッファ (なければカーソル行) の名前 / ファイル名をコピーする (空白区切り) |
| `C-u 0 yf` | ファイル名をフルパスでコピーする |
| `C-u yf` | ファイル名を、ibuffer のディレクトリからの相対パスでコピーする |
| `M-h` | ibuffer で使えるキーの一覧 (embark-bindings。絞り込んで実行もできる) |

`SPC b` は「1 つ選んで開く・消す」、`SPC B` は「見渡して、まとめて操作する」と使い分ける。

## consult-buffer から ibuffer に書き出す

- [ ] `SPC b` → `b SPC` で候補をバッファだけにし、`py` と入力する。`main.py` と `utils.py` に絞られたところで `M-e` を押す。
      2 つだけを並べた ibuffer が開く。ここでもレッスン 3〜11 の操作がそのまま使える。
- [ ] `t` で 2 つに印を付け、`=` で差分を見る (変更がなければ空)。`q` で閉じる。
- [ ] `main.py` に何か書き足してから、`SPC b` → `* SPC` と押す。変更のあるバッファだけが候補に出る。`C-g` で閉じ、`main.py` の変更は `SPC B` → `V` で捨てる。

## ibuffer を開かずに消す

- [ ] `SPC b` で `plot.R` を選んだ状態で (`RET` は押さない)、`M-a` → `k` と押す。`plot.R` のバッファが消える。

## 名前をコピーして使う

- [ ] ibuffer で `main.py` と `analysis.R` に印を付け、`yb` を押す。エコーエリアにバッファ名が空白区切りで出て、コピーされる。
- [ ] そのまま `C-u 0 yf` を押す。フルパスがコピーされる。`M-!` (shell-command) で `wc -l ` と入力してから `C-y` で貼り付け、`RET`。
      2 つのファイルの行数が出る。`U` で外す。

## 作業の終わりに片付ける

- [ ] `SPC d` → `RET` で dired をいくつか開き、`<f1> f` → `ibuffer` → `RET` でヘルプを開いておく。
- [ ] `SPC B` で ibuffer を開き、`* u` → `S` で、保存し忘れたファイルをまとめて保存する (なければ何も起きない)。
- [ ] `* /` で dired のバッファに印を付け、`* h` でヘルプのバッファにも印を加える。`D` → `y` でまとめて消す。
- [ ] `M-h` を押して、`sort` と入力する。ibuffer の並べ替えのキーが一覧になる。1 つ選ぶと、そのまま実行される。
