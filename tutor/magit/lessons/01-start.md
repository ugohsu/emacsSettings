# レッスン 1: git の考え方と最初のコミット (`01-start`)

## git の考え方

git は、ファイルの変更の履歴を残す道具。履歴の 1 つ 1 つを**コミット**と呼ぶ。
コミットは「その時点のファイルの状態の記録」で、メッセージ・作者・日時と、ID (ハッシュ。`5b4d47c` のような英数字) が付く。
あとから、いつ・誰が・何を変えたのかを見たり、前の状態に戻したりできる。

git は、ファイルの状態を 3 つの場所に分けて考える。

```
 作業ツリー  ── stage (git add) ──▶  ステージ  ── commit (git commit) ──▶  リポジトリ
(ふだん編集する                    (次のコミットに                      (コミットの積み重ね。
 ファイル)                          入れる変更)                          .git の中にある)
```

- **作業ツリー**: ふだん編集しているファイルそのもの。
- **ステージ** (インデックスとも呼ぶ): 次のコミットに入れる変更を、選んで置いておく場所。
  ステージに置くことを **stage する** と言う。変えたファイルのうち一部だけをコミットできるのは、このため。
- **リポジトリ**: コミットの積み重ね (履歴)。ディレクトリ直下の `.git` の中にある (`.git` を消すと履歴も消える)。

magit のステータス画面 (`git status` にあたる) は、この 3 つの間の違いを一覧にしたもの。

| 見出し | 意味 |
|---|---|
| `Head:` (1 行目) | 今いるブランチ (レッスン 5) と、その最新のコミット |
| `Untracked files` | git がまだ管理していない (一度も stage していない) ファイル |
| `Unstaged changes` | 最後のコミットから変えたが、まだ stage していない変更 |
| `Staged changes` | stage した変更 (次のコミットに入る) |
| `Recent commits` | 最近のコミット |

見出しのうち `Untracked files` と `Recent commits` は、最初は閉じている (`TAB` で開く)。

## 操作

| キー | 動作 | git コマンド |
|---|---|---|
| `SPC g` (`C-x g`) | ステータス画面を開く (リポジトリでなければ、作るかを聞く) | `git status` (作るときは `git init`) |
| `TAB` | カーソルの位置のセクション (見出しやファイル) を開く・閉じる | |
| `j` / `k` | 1 行ずつ動く | |
| `C-j` / `C-k` | 次 / 前のセクションへ | |
| `gj` / `gk` | 同じ階層の次 / 前のセクションへ (見出しから見出しへ、など) | |
| `gn` / `gu` / `gs` | `Untracked files` / `Unstaged changes` / `Staged changes` の見出しへ飛ぶ | |
| `s` | カーソルの位置のファイルを stage する | `git add ファイル` |
| `u` | stage を外す | `git restore --staged ファイル` |
| `c c` | コミットする (メッセージを書くバッファが開く) | `git commit` |
| `ZZ` (`C-c C-c`) | (メッセージのバッファで) コミットを確定する | |
| `ZQ` (`C-c C-k`) | (メッセージのバッファで) コミットをやめる | |
| `gr` | 画面を新しくする | |
| `q` | 閉じる | |
| `?` (`h`) | magit のメニュー (使えるコマンドの一覧)。`C-g` で閉じる | |
| `` ` `` | magit が実行した git コマンドと、その出力を見る (プロセスバッファ) | |
| `\|` | git コマンドを入力して実行する | `git …` |

## リポジトリを作る

- [ ] 右の dired で `01-start` に入り (`l`)、`SPC g` を押す。ここはまだリポジトリではないので、`Git repository:` と聞かれる。
      そのまま `RET` を押すと `Create repository in ~/magit-tutor/01-start/? (y or n)` と聞かれるので、`y` で答える。
      `git init` が実行されて (ディレクトリに `.git` ができる)、右側にステータス画面が開く。
- [ ] 1 行目には、まだコミットがないので `In the beginning there was darkness` (はじめに闇があった) と出る。
      最初のコミットをすると、ここが `Head:` の行になる。
- [ ] `Untracked files (2)` の行で `TAB` を押すと、`memo.txt` と `plan.md` が出る。もう一度 `TAB` で閉じ、また開いておく。
- [ ] `j` / `k` で 1 行ずつ、`C-j` / `C-k` でセクションごとに動いてみる。

## 名前とメールアドレスを確かめる

コミットには作者の名前とメールアドレスが記録される。パソコンごとに、最初に一度だけ設定しておく。

- [ ] `|` を押すと、入力欄に `git ` と入った状態になる。続けて `config user.name` と入力して `RET`。
      プロセスバッファが開き、`0 git config user.name` の下に名前が出る。`q` で閉じる。
- [ ] 同じように `|` で `config user.email` を実行して、メールアドレスを確かめる。
- [ ] 何も出ない (行の先頭の数字が `0` ではなく `1`) ときは、まだ設定していない。`|` で次のように設定する
      (入力欄は `git ` から始まるので、その続きを入力する。`--global` は、このパソコンのすべてのリポジトリで使う設定にする
      という意味で、`~/.gitconfig` に書かれる)。GitHub に push するなら、メールアドレスは GitHub に登録したもの
      (か、GitHub が用意する `…@users.noreply.github.com`) にする。

```
git config --global user.name "山田 太郎"
git config --global user.email "taro@example.com"
```

git コマンドがエラーで終わると、エコーエリアに ``Git error: … [Type ` to see …]`` のように出る。
そのときも `` ` `` でプロセスバッファを開くと、git が出したメッセージ (何がいけなかったか) が読める。

## 最初のコミット

- [ ] `memo.txt` の行で `s` を押す。`memo.txt` が `Staged changes` に移る (`new file   memo.txt`)。これが `git add memo.txt`。
- [ ] `` ` `` を押すと、プロセスバッファに `git … add -- memo.txt` と出ている。magit の操作は、裏で git コマンドを実行しているだけ。
      `…` は、magit が付け足したオプションを省いた印。`q` で閉じる。
- [ ] `c` を押すと、画面の下にコミットのメニューが出る。`-a` などは `git commit` のオプション、`c` (Commit) などは実行するコマンド。
      `c` を押す。メッセージを書くバッファ (`COMMIT_EDITMSG`) が開き、隣のウィンドウに、これからコミットする変更が出る。
- [ ] `i` を押して 1 行目に `買い物リストを追加` と書き、`ESC` → `ZZ` でコミットする。
      `#` で始まる行は説明で、メッセージには入らない。
- [ ] ステータス画面に戻る (隣のウィンドウに差分が残っていたら、そちらに移って (`C-w w` で、ウィンドウを順に移れる) `q` で閉じる)。
      1 行目が `Head:     main 買い物リストを追加` になる (`main` は今のブランチの名前)。
      `Recent commits` を `TAB` で開くと、今のコミットが ID (先頭の英数字) と一緒に出る。
- [ ] `plan.md` も同じように `s` → `c c` → `計画を追加` → `ZZ` でコミットする。`Untracked files` がなくなる。

## ファイルを書き換えてコミットする

ふだんの作業は「ファイルを書き換える → stage する → コミットする」の繰り返しになる。

- [ ] `C-x C-f` で `memo.txt` を開き (magit の画面では `SPC f` が使えないので `C-x C-f`)、`- 卵` の行を書き足して `:w` で保存する。
- [ ] `SPC g` でステータス画面に戻る。`Unstaged changes (1)` に `modified   memo.txt` が出る。
      その行で `TAB` を押すと、差分 (`+- 卵`) が出る。`+` で始まる行が足した行。
- [ ] `s` で stage し、`c c` を押す。メッセージのバッファで、何も書かずに `ZQ` を押すと、コミットをやめる (stage はそのまま残る)。
- [ ] もう一度 `c c` を押し、`卵を追加` と書いて `ZZ` でコミットする。
- [ ] `q` でステータス画面を閉じ、`SPC g` で開き直す (リポジトリになったので、もう聞かれない)。
- [ ] `?` を押すと、magit のコマンドの一覧が出る。各レッスンで使うキーは、ここから探せる。`C-g` で閉じる。
