# レッスン 2: 差分を見る・選んで stage する (`02-stage`)

コミットは「意味のまとまり」ごとに分けると、あとで履歴を読みやすく、戻しやすい。
1 つのファイルに別々の変更が混ざっていても、magit なら一部だけを選んで stage し、別々にコミットできる。

**差分 (diff) の読み方**: `-` で始まる行は消した行、`+` で始まる行は足した行、空白で始まる行は変えていない前後の行。
変更のかたまりを **hunk** と呼び、`@@ -17,6 +18,7 @@` がその見出し
(「元のファイルの 17 行目からの 6 行が、新しいファイルでは 18 行目からの 7 行になった」という意味)。

| キー | 動作 | git コマンド |
|---|---|---|
| `TAB` (ファイルの行で) | 差分を開く・閉じる | `git diff ファイル` |
| `s` / `u` | (ファイル・hunk・選んだ行を) stage する / stage を外す | `git add` / `git restore --staged` (一部だけなら `git add -p` / `git restore --staged -p`) |
| `V` (`v`) で選んで `s` | 選んだ行だけを stage する | `git add -p` (hunk を `e` で編集) |
| `S` | 追跡しているファイルの変更を、すべて stage する | `git add -u` |
| `U` | stage をすべて外す | `git restore --staged .` |
| (見出しの行で) `s` / `u` | その見出しの下を、すべて stage する / 外す | |
| `d s` / `d u` | stage した / していない変更の差分を、別のバッファで見る | `git diff --staged` / `git diff` |
| `d d` | カーソルの位置に応じた差分を、別のバッファで見る | `git diff …` |
| `SPC` | (ファイルの行で) 差分を別のウィンドウに出す。もう一度押すとスクロール (`DEL` で戻る) | |
| `+` / `=` / `~` | 差分の前後に出す行を増やす / 減らす / 元に戻す | `git diff -U5` など |
| `RET` | (差分の中で) ファイルを開き、その行に移る | |
| `c` の画面で `-a` を付けて `c` | 追跡しているファイルの変更をすべて stage して、コミットする | `git commit -a` |

## hunk を選んで stage する

- [ ] 右の dired で `02-stage` に入り、`SPC g`。`Unstaged changes (2)` に `README.md` と `analysis.py` が出る。
      `Untracked files (1)` を `TAB` で開くと `notes.txt` が出る。
- [ ] `analysis.py` の行で `TAB` を押すと、差分が開く。`@@` で始まる hunk が 2 つある。
      1 つ目は `import sys` を足した変更、2 つ目は最大値を表示する行を足した変更。
- [ ] `C-j` を 2 回押して (1 回目で 1 つ目、2 回目で 2 つ目の hunk の `@@` の行に移る)、`s` を押す。その hunk だけが `Staged changes` に移る。
      `analysis.py` は、`Unstaged changes` (1 つ目の hunk) と `Staged changes` (2 つ目の hunk) の両方に出る。
- [ ] `d s` を押すと、stage した変更の差分 (`git diff --staged`) が別のウィンドウに出る。次のコミットに入るのは、これだけ。
      そのウィンドウに移って (`C-w w` で、ウィンドウを順に移れる) `q` で閉じる。
- [ ] `c c` で `最大値も表示する` とコミットする。`Unstaged changes` には `import sys` の変更が残っている。

- [ ] `README.md` の行で `TAB` を押す。足した行が 2 つある (`+- 最大値も表示する` と `+- (メモ) グラフはあとで考える`)。

      2 行目を空け、3 行目から詳しい説明を書いてもよい (下の「コミットメッセージの書き方」)。

## 差分の見方を変える

- [ ] `C-x C-f` で `analysis.py` を開き、`print("件数:", len(rows))` の行を消して `:w` で保存する。`SPC g` で戻る。
- [ ] `analysis.py` で `TAB` を押して差分を開き、`+` を何回か押す。前後に出る行が増える。`=` で減り、`~` で元に戻る。
- [ ] `-` で始まる行で `RET` を押すと、`analysis.py` が開き、その場所に移る。`SPC g` でステータス画面に戻る。
- [ ] `analysis.py` の行 (ファイル名の行) で `SPC` を押すと、差分が別のウィンドウに出る (カーソルはステータス画面に残る)。
- [ ] 消した行は、`x` で元に戻しておく (変更を捨てる。詳しくはレッスン 3)。

## コミットメッセージの書き方

- 1 行目は、何をしたのかを短く (日本語なら 25 字ほど、英語なら 50 字ほどまで) 書く。履歴の一覧にはこの行が出る。
- 詳しく書くときは、2 行目を空けて、3 行目から「なぜそうしたのか」を書く (何をしたのかは差分を見れば分かる)。
- 1 つのコミットには 1 つの目的の変更だけを入れる。別の目的の変更は、このレッスンのように分けてコミットする。
