# レッスン 4: 履歴を見る (`04-log`)

コミットは ID (ハッシュ) で指すほか、今のコミットからの位置でも指せる。

| 書き方 | 意味 |
|---|---|
| `HEAD` | 今いるコミット (今のブランチの先頭) |
| `HEAD~1` (`HEAD~`) / `HEAD~3` | 1 つ前 / 3 つ前のコミット |
| `main` | ブランチ `main` の先頭のコミット |
| `75f775c` | ID (ハッシュ) の先頭の 7 文字ほど。ほかと区別できれば短くてよい |
| `A..B` | A から B までの間のコミット (A は含まない) |

| キー | 動作 | git コマンド |
|---|---|---|
| `l l` | 今のブランチの履歴 | `git log` |
| `l a` | すべてのブランチ・タグの履歴 | `git log --all` |
| (履歴の中で) `j` / `k` → `SPC` | カーソルのコミットの内容を、別のウィンドウに出す (もう一度押すとスクロール、`DEL` で戻る) | `git show コミット` |
| (履歴の中で) `RET` | カーソルのコミットの内容を開き、そちらに移る (`q` で戻る) | `git show コミット` |
| `l` の画面で `-F` | メッセージで絞り込む | `git log --grep=文字列` |
| `l` の画面で `-A` | 作者で絞り込む | `git log --author=名前` |
| `l` の画面で `--` | ファイルで絞り込む | `git log -- ファイル` |
| `l` の画面で `-G` | 変更の中身 (足した・消した行) で絞り込む | `git log -G正規表現` |
| (履歴の中で) `V` で選んで `d r` → `RET` | 選んだ 2 つのコミットの間の差分 | `git diff A..B` |
| `C-c M-g l` (ファイルを開いたバッファで) | そのファイルの履歴 | `git log -- ファイル` |
| `C-c M-g b` (ファイルを開いたバッファで) | 行ごとに、最後に変えたコミットを出す (blame) | `git blame ファイル` |
| `C-c M-g p` (ファイルを開いたバッファで) | 1 つ前の版のファイルを開く (そこで `gk` / `gj` で前 / 次の版へ) | `git show コミット:ファイル` |

`C-c M-g` (magit-file-dispatch) は、ファイルを開いたバッファで使う magit のメニュー。
`-F` などの絞り込みは、`l` の画面でもう一度同じキーを押すと外れる (`--` だけは入力し直しになる)。
履歴のバッファを `q` で閉じて開き直しても外れる。

## 履歴を見る

- [ ] 右の dired で `04-log` に入り、`SPC g`。`Recent commits` を `TAB` で開くと、最近の 10 個のコミットが出る。
- [ ] `l l` を押すと、履歴のバッファが開く。左から ID、`*` (ブランチの分かれ方を表すグラフ)、メッセージ。右端に作者と、どれくらい前のコミットか。
- [ ] `j` / `k` で `グラフを描く` の行に移り、`SPC` を押す。そのコミットの内容 (作者・日時・メッセージ・差分) が別のウィンドウに出る。
      カーソルは履歴に残るので、`j` → `SPC` → `j` → `SPC` … と押していくと、1 つずつ順に見ていける。
- [ ] `RET` を押すと、コミットの内容のバッファに移る。`q` で履歴に戻る。

## 絞り込む

- [ ] 履歴のバッファで `l` を押し、`-F` → `グラフ` → `RET` → `l` と押す。メッセージに `グラフ` を含む 3 つのコミットだけが出る。
- [ ] `l` → `-F` (もう一度押すと外れる) → `-A` → `sato` → `RET` → `l`。sato が書いた 4 つのコミットだけが出る。
- [ ] `l` → `-A` (外す) → `-G` → `mean` → `RET` → `l`。`mean` を含む行を足した (か消した) コミット (`平均を計算する`) だけが出る。
      「この関数はいつ入ったのか」を探すのに使う。
- [ ] `l` → `-G` (外す) → `--` → `analysis.R` → `RET` → `l`。`analysis.R` を変えたコミットだけが出る。
      `q` で履歴を閉じ、`l l` で開き直すと、絞り込みが外れている。

## 2 つのコミットの差分

- [ ] 履歴のバッファで `グラフを描く` の行に移り、`V` を押してから `3k` で `考察を書く` の行まで選ぶ。
      `d r` を押すと `Diff for range` と聞かれ、既定が選んだ 2 つのコミットの範囲になっているので `RET`。その間に入った変更がまとめて出る。`q` で閉じる。

## ファイルの履歴と blame

- [ ] `q` で履歴を閉じ、`C-x C-f` で `analysis.R` を開く。`C-c M-g` を押すとファイル用のメニューが出るので、`l` (Log) を押す。
      `analysis.R` を変えたコミットだけの履歴が出る。`j` → `SPC` で順に見ていき、`q` で閉じる。
- [ ] `analysis.R` で `C-c M-g b` を押す (blame)。行のかたまりごとに、その行を最後に変えたコミット (メッセージ・作者・日時) が見出しになって出る。
      `gj` / `gk` で次 / 前のかたまりへ動き、`RET` でそのコミットの内容を見る。`q` で blame を抜ける。
- [ ] `analysis.R` で `C-c M-g p` を押す。最後にコミットした版の `analysis.R` が、読み取り専用で開く (バッファ名に `.~ID~` が付く)。
      `gk` を何回か押すと、さらに前の版へ、`gj` で新しい版へ移る。古い版を見ながら、今のファイルと比べたいときに使う。`q` で閉じる。

`SPC g` で開くステータス画面の `Recent commits` は直近の 10 個だけなので、それより前は `l l` で見る。
