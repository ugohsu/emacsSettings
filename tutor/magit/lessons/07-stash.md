# レッスン 7: 作業を一時的に退避する (`07-stash`)

書きかけの変更があるときに、急ぎで別のことをしたくなることがある (別のブランチに切り替える、pull する、小さな修正だけを先にコミットする、など)。
**stash** は、コミットしていない変更を一時的に退避して、作業ツリーを最後のコミットの状態に戻す。用事が済んだら、退避した変更を戻す。

| キー | 動作 | git コマンド |
|---|---|---|
| `z z` | 変更 (stage したものも、していないものも) を退避する | `git stash` (`git stash push`) |
| `z` の画面で `-u` を付けて `z` | 追跡していないファイルも一緒に退避する | `git stash -u` |
| `z i` | stage した変更だけを退避する | `git stash push --staged` |
| `z p` | 退避した変更を戻し、退避の一覧から消す | `git stash pop` |
| `z a` | 退避した変更を戻す (一覧には残す) | `git stash apply` |
| `z k` | 退避を捨てる | `git stash drop` |
| `z l` | 退避の一覧 | `git stash list` |
| (`Stashes` の行で) `RET` / `a` / `A` / `x` | 中身を見る / 戻す (残す) / 戻す (消す) / 捨てる | `git stash show -p` / `apply` / `pop` / `drop` |

## 書きかけを退避して、先に別のコミットをする

- [ ] 右の dired で `07-stash` に入り、`SPC g`。`Unstaged changes` に、書きかけの `report.md` がある
      (`TAB` で見ると `(書きかけ) 実験の準備をした。`)。`Untracked files` には `idea.txt` がある (`TAB` で開くと見える)。
- [ ] ここで、`README.md` の誤字 (`げんこう`) に気づいたとする。書きかけの `report.md` は混ぜずに、誤字の修正だけを先にコミットしたい。
- [ ] `z z` を押す。`Stash message` と聞かれるので、そのまま `RET` (`On main: …` という名前になる。分かりやすい名前を付けてもよい)。
      `report.md` の変更が消え、`Stashes (1)` が増える。`idea.txt` は追跡していないので、退避されずに残る。
- [ ] `C-x C-f` で `README.md` を開き、`げんこう` を `原稿` に直して `:w`。`SPC g` で戻り、`s` → `c c` → `誤字を直す` でコミットする。
- [ ] `z p` を押す。`Pop stash` と聞かれ、候補の一番上に `stash@{0}` (一番新しい退避) が選ばれているので、そのまま `RET`。
      `report.md` の書きかけが戻り、`Stashes` が消える。

## 追跡していないファイルも退避する・中身を見る

- [ ] `z` を押し、メニューで `-u` を押してから (`--include-untracked` が付く)、`z` を押す。`RET` で名前はそのまま。
      今度は `idea.txt` も退避され、ステータス画面から変更の見出しがなくなる。
- [ ] `Stashes (1)` の行で `TAB` を押して開き、`stash@{0}` の行で `RET`。退避した中身 (差分) が見える。`q` で戻る。
- [ ] `stash@{0}` の行で `a` を押す。変更が戻るが、退避は一覧に残っている (同じ変更を、別のブランチでも戻したいときなどに使う)。
- [ ] `stash@{0}` の行で `x` を押し、確認に `y` で答えて、退避を捨てる。

退避はいくつでも積める (新しいものが `stash@{0}`、その前が `stash@{1}` …)。ただし、長く置いておくと何の変更だったか忘れやすい。
しばらく続ける作業なら、stash ではなくブランチを作ってコミットしておくほうがよい。
