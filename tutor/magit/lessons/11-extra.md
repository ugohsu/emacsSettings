# レッスン 11: 無視するファイル・ファイルの操作・タグ (`11-extra`)

| キー | 動作 | git コマンド |
|---|---|---|
| `i t` | ファイルやパターンを、`.gitignore` に書いて無視する (リポジトリに入れて、ほかの人とも共有する) | (`.gitignore` に書き足す) |
| `i p` | 自分の手元だけで無視する (`.git/info/exclude` に書く。共有しない) | (`.git/info/exclude` に書き足す) |
| `R` | ファイルの名前を変える・移す | `git mv 元 先` |
| `X` | ファイルを追跡しないようにする (ファイルは消さない) | `git rm --cached ファイル` |
| `t t` | タグを付ける (`v1.0` のような、コミットに付ける名札。ブランチと違って動かない) | `git tag 名前 コミット` |
| `t x` | タグを消す | `git tag -d 名前` |
| `p t` / `p T` | すべてのタグ / 1 つのタグを push する | `git push --tags` / `git push origin タグ` |
| `C-c M-g s` / `C-c M-g d` (ファイルを開いたバッファで) | そのファイルを stage する / そのファイルの差分を見る | `git add ファイル` / `git diff ファイル` |
| `C-c M-g c` (ファイルを開いたバッファで) | コミットのメニューを出す (`c c` と同じ) | `git commit` |
| `M-h` | 今のバッファで使えるキーとコマンドの一覧 (絞り込んで実行もできる) | |

## 無視するファイル

実行のたびに書き換わるログ、一時ファイル、出力したデータなどは、git で管理しない。
`.gitignore` に書いておくと、`Untracked files` にも出なくなる。

- [ ] 右の dired で `11-extra` に入り、`SPC g`。`Untracked files` を `TAB` で開くと、`output.log` と `cache/` がある。
- [ ] `output.log` の行で `i t` を押す。`File or pattern to ignore` の候補に `/output.log` と `*.log` がある。
      `*.log` (拡張子が `.log` のファイルをすべて) を選んで `RET`。`output.log` が消え、代わりに `.gitignore` が出る。
- [ ] `cache/` の行で `i t` → `/cache/` を選んで `RET`。
- [ ] `.gitignore` の行で `RET` を押して開き、中身が `*.log` と `/cache/` の 2 行であることを確かめる。`SPC g` で戻り、
      `.gitignore` で `s` → `c c` → `生成されるファイルを無視する` でコミットする。
      `.gitignore` もリポジトリに入れておくと、clone したほかの人の手元でも同じように無視される。

自分の環境だけのファイル (エディタの設定など) は、`i p` で `.git/info/exclude` に書く。こちらはリポジトリに入らない。

## ファイルの名前を変える・追跡をやめる

- [ ] `R` を押す。`Rename file` で `old` と入力して `old_name.md` を選び `RET`、移す先に `manual.md` と入力して `RET`。
      `Staged changes` に `renamed   old_name.md -> manual.md` と出る。`c c` → `手順書の名前を変える` でコミットする。
      dired などで名前を変えても、git は「消して、新しく足した」と見て、中身が似ていれば名前の変更として扱う。
- [ ] `secret.txt` には、本当は管理してはいけないもの (パスワードなど) が入っているとする。`X` を押し、`Untrack file` で `secret` と入力して `secret.txt` を選び `RET`。
      `Staged changes` に `deleted   secret.txt` (リポジトリからは消す)、`Untracked files` に `secret.txt` (ファイルは残る) が出る。
- [ ] `secret.txt` の行で `i t` → `/secret.txt` を選び、`.gitignore` に足す。`S` → `c c` → `secret.txt を管理から外す` でコミットする。

追跡をやめても、**過去のコミットには残っている** (`l l` で前のコミットを見れば読める)。push してしまったパスワードなどは、
履歴から消すよりも、パスワード自体を変えるほうが確実。最初から `.gitignore` に入れておく。

## タグを付ける

- [ ] `t t` を押し、`Create tag` に `v1.0` と入力して `RET`。`Place tag on` は今のコミットのまま `RET`。
- [ ] `yr` で一覧を開くと、`Tags` の下に `v1.0` がある。`l l` で見ると、そのコミットに `v1.0` が付いている。
      論文を投稿したとき、発表したときなど、あとで戻ってきたい時点に付けておく。
- [ ] `t x` → `v1.0` → `RET` で消せる (確かめたら、もう一度付けておいてもよい)。

## ファイルを開いたまま操作する

ステータス画面を開かなくても、ファイルを開いたバッファから、そのファイルについての操作ができる。

- [ ] `C-x C-f` で `analysis.py` を開き、`print("完了")` の行を書き足して `:w`。
- [ ] `C-c M-g` を押すと、ファイル用のメニューが出る。`d` を押すと、このファイルの差分が出る。`q` で閉じる。
- [ ] `C-c M-g s` でこのファイルを stage し、`C-c M-g c` → `c` → `完了を表示する` → `ZZ` でコミットする。

## キーを忘れたら

- [ ] ステータス画面で `M-h` を押し、`stash` と入力する。stash に関係するキーとコマンドの一覧に絞られる。
      選んで `RET` を押すと、そのまま実行される (ここでは `C-g` でやめる)。
- [ ] `?` を押すと、magit のメニュー全体が出る (`C-g` で閉じる)。
