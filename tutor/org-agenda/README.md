# org-agenda

org-agenda の操作のメモ。キーはこのリポジトリの `init.el` (evil と evil-collection) を前提にしている。
evil-collection に org-agenda の設定があるので、素の org-agenda とはキーがかなり違う (素の `b`・`f`・`j` は `H`・`L`・`J`)。
設定は `init.el` の org の節にある。当分は素の agenda を使い、何が欲しいかを見る (2026-10-18)。課題 (lessons) はない。

## クイックガイド

使い方を忘れたときは、この節を読めば org-agenda の全体がつかめるようにしている。

### この設定で見えるもの

- 対象は `~/wdir/org/sample/projects/` の org ファイル (`org-agenda-files`)。本運用では `projects/` に替える
- 見出しのログの日付 (`- [2026-10-16 金] ...`) も拾う。日表示にすると、その日にログを書いた見出しが、ログの行の数だけ並ぶ
- 行の頭はファイル名と見出しの階層 (`gakunai:   大学院担当科目->ログ`)。ログの本文は一覧に出ないので、`TAB` で開いて読む
- 予定・期限の正本は Google Calendar・Tasks。見出しの `:DUE:` はプロパティの写しなので、agenda には出ない

### キーの決め方

- agenda のキーは evil-collection が決めている。evil-collection の割り当てはそのまま使い、上書きしない
- evil の `j`・`k`・`gg`・`G` はそのまま使える。`/` で探せるが、次へ進む `n` はメモの追加になっている (下の「使わないキー」)
- 自分の設定で変えたのは、normal state の `C-h` (このガイド) だけ

### 開く・閉じる

- `M-x org-agenda` のあと `a`: agenda を開く (最初は今週)。最初の画面 (どの一覧を作るかを選ぶ) では evil のキーは効かない。`q` で抜ける
- `q` (`ZZ`): 閉じる
- `x` (`ZQ`): 閉じて、agenda が読み込んだ org のバッファもまとめて閉じる (自分で開いていたバッファは閉じない)。
  ibuffer で片づける手間が減る。保存していない変更があれば、保存するかを聞かれる
- `gr`: 作り直す (org を直したあと。agenda は自動では変わらない)

### 日をたどる

- `vd` / `vw` / `vm` / `vy`: 日 / 週 / 月 / 年の表示にする (ログをたどるなら日表示が見やすい)
- `H` / `L`: 前 / 次の期間へ (日表示なら 1 日、週表示なら 1 週)
- `.`: 今日へ
- `J`: 日付を打って飛ぶ。`10/16` (10 月 16 日)、`-3` (3 日前)、`-1w` (1 週前) のように打てる。
  出てくるカレンダーの上で `S-<left>` / `S-<right>` を押すと 1 日ずつ動く

### 動く・読む

- `j` / `k`: 1 行ずつ。`gj` / `gk` (`C-j` / `C-k`): 次 / 前の項目へ (日付の行を飛ばす)。`]]` / `[[`: 次 / 前のブロックへ
- `TAB`: 項目を別のウィンドウに開き、そちらへ移る。ログの項目なら、その日のログの行を画面の中ほどに出し、カーソルはその上の
  「ログ」の見出しに置く (ログが長いと、行が画面の外に出ることがある)。agenda は残るので、`SPC h`・`SPC l` などで戻る
- `RET`: 項目をこのウィンドウで開く (agenda は隠れる。`SPC b` で `*Org Agenda*` に戻る)
- `go` (`S-RET`): 項目の中のリンクを開く
- follow モード: 一覧で動くと、隣のウィンドウにその項目が出る (`TAB` と同じ出し方で、カーソルは agenda に残る)。
  キーがないので `M-x org-agenda-follow-mode` で入れる (もう一度で止める)。日表示で `gj` / `gk` を押すと、その日のログを順に読める

### 絞り込む

- `f`: タグで絞り込む (`claude` など)。`F`: 絞り込みをすべて外す

### 使わないキー (org のファイルを書き換える)

agenda から org のファイルを書き換えるキー。予定・期限・完了の正本は Google にあり、ログは手で書くので、この運用では使わない。

- `d`: 項目の見出しを、中身ごと消す (確認が出るので `n` で止める)。ログの項目なら、その行だけでなく「ログ」の見出しが全部消える
- `t` (TODO の状態)・`s` (SCHEDULED)・`D` (DEADLINE)・`p` (優先度)・`n` (メモを足す)
- `r` (ほかの見出しへ移す)・`A` (アーカイブへ移す)・`T` (タグを付ける・外す)
- `I` / `O` / `X` (時間を測る clock)、`m` / `u` / `B` (印を付けて、まとめて操作する)
- `S`: 開いている org のバッファをすべて保存する
- 押してしまったら、`TAB` で org のバッファに移って、evil の `u` で戻す (agenda の `u` は印を外すキーで、取り消しではない)

### 困ったとき

- `C-h` (normal state): このクイックガイドを別のウィンドウに出す (`q` で閉じる)
- `M-h`: 今のバッファで使えるキーをすべて一覧する (embark-bindings。agenda では org と違って使える)。`<f1> b` でも見られる
- `<f1> k` のあとにキー: そのキーが何をするかを見る
