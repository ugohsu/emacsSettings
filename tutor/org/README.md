# org

org-mode の操作のメモ。キーはこのリポジトリの `init.el` (evil と自分の設定) を前提にしている。
evil-collection には org の設定がなく、evil-org も使っていないので、org のキーは evil のキー、
evil-collection の outline-mode の設定 (org は outline-mode を元にしているので、これが効く)、
org の標準のキー (`C-c` や `M-` で始まるもの) の組み合わせになる。dired などと違い、課題 (lessons) はまだない。

## クイックガイド

使い方を忘れたときは、この節を読めば org の全体がつかめるようにしている。

### キーの決め方

- evil のキーはそのまま使える (`j`・`k`・`gg`・`G` で動き、`/`・`n` で検索し、`i`・`a`・`o` で書く)。
- normal state の `gj`・`gk`・`]]`・`[[`・`z…`・`M-h`・`M-l`・`M-j`・`M-k` は、evil-collection の outline-mode の設定で
  見出しの操作になっている (`gj`・`gk` は折り返した行の中の移動ではない)。evil-collection の割り当てはそのまま使い、上書きしない。
  考え方は evil-collection の README の Guidelines (https://github.com/emacs-evil/evil-collection) にある。
- org の操作は `C-c` か `M-` で始まる。normal state でも insert state でも同じように効く。
  `C-c` を押して少し待つと、続くキーの一覧が出る (which-key)。
- 自分の設定で変えたのは、normal state の `RET` (リンクを開く)・`C-h` (このガイド) の 2 つだけ。

### 見る・動く

- `TAB`: 見出しの上で、開く・閉じるを切り替える。`S-TAB`: ファイル全体を切り替える (概要 → 見出し → すべて)
- `SPC o`: 見出しの一覧から選んで飛ぶ (consult-outline)
- `gj` / `gk` (`C-j` / `C-k`): 同じ階層の次 / 前の見出しへ。`]]` / `[[`: 次 / 前の見出しへ (階層を問わない)。`zu`: 親の見出しへ
  (org の `C-c C-f` / `C-c C-b`、`C-c C-n` / `C-c C-p`、`C-c C-u` と同じ)
- `SPC /`: 中身を絞り込んで探す (consult-line)

### 畳む・開く (z で始まるキー。vim の折りたたみと同じ考え方)

- `za`: カーソルの見出しを開く・閉じる (`TAB` と同じ)。`zc` / `zo`: 閉じる / 開く。`zO`: 子孫まですべて開く
- `zm` / `zr`: ファイル全体を閉じる (見出しだけにする) / すべて開く
- `zp`: カーソルの見出しのほかをすべて畳む (今の作業に集中する)
- `zk`: 直下の子の見出しだけを出す。`zK`: 子孫の見出しをすべて出す (本文は出さない)
- `ze` / `zE`: 見出しの本文だけを出す / 隠す (子の見出しはそのまま)。`zB`: ファイル全体の本文を隠す。`zl`: カーソルの見出しの中の本文を隠す

### リンク

- `RET` (normal state): カーソルの上のリンクを開く (`[[file:…::*見出し]]` ならその見出しへ飛ぶ)。
  リンクの上でなければ、evil の `RET` と同じく次の行へ動く。`C-c C-o` でも開ける
- `C-o`: リンクを開く前の場所に戻る (evil の jump list)。`C-c &` でも戻れる
- `C-c C-l`: リンクを挿入する・カーソルの上のリンクを直す

### チェックボックス

- `C-c C-c`: `- [ ]` の行で、チェックを付ける・外す
- `M-S-RET`: チェックボックスの項目を、今の項目の下に足す (`M-RET` はチェックボックスなしの項目を足す)。
  insert state で押すと、そのまま続けて書ける

### 見出しやリストを組み替える

- `M-h` / `M-l` (normal state): 見出しを子もいっしょに一段上げる / 下げる。`M-k` / `M-j`: 見出しを中身ごと上 / 下と入れ替える
- `M-<left>` / `M-<right>`: 見出し・リストの項目を一段上げる / 下げる (`M-S-<left>` / `M-S-<right>` は子もいっしょに)。
  リストの項目はこちらで動かす (リストの中で `M-h` などを押すと、項目ではなく、それを含む見出しが動く)
- `M-<up>` / `M-<down>`: 見出し (中身ごと)・リストの項目を、上 / 下と入れ替える
- `M-RET`: 次の見出し・リストの項目を足す (見出しの上なら見出し、リストの中なら項目)

### 改行 (auto-fill)

- 打っていて 80 桁を超えると、自動で改行が入る (org だけ。markdown などはそのまま)。リストの中なら続きの行も字下げされる
- `M-q`: カーソルの段落を 80 桁に整え直す (あとから直して行の長さが不揃いになったときや、貼り付けたあと)。
  `#+` の行・コメント・表・`#+begin_example` の中は崩さない
- evil の `gq` は使わない。org の構造を見ずに詰めるので、`#+TITLE:` と `#+STARTUP:` の行などをつなげてしまう
- 貼り付けた原文 (チャットのログなど) は、改行を残したいので `#+begin_example` … `#+end_example` に入れる
- 長い URL と表は改行できないので、そこだけは見切れる (org の既定)

### タグ

- `C-c C-q`: 見出しにタグを付ける・外す

### 困ったとき

- `C-h` (normal state): このクイックガイドを別のウィンドウに出す (`q` で閉じる)。insert state では backspace のまま
- `<f1> b`: 今のバッファで使えるキーをすべて一覧する (org の normal state では `M-h` が見出しの昇格なので、embark-bindings は使えない)
- `<f1> k` のあとにキー: そのキーが何をするかを見る
