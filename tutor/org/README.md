# org

org-mode の操作のメモ。キーはこのリポジトリの `init.el` (evil と自分の設定) を前提にしている。
evil-collection には org の設定がなく、evil-org も使っていないので、org のキーは evil のキーと
org の標準のキー (`C-c` や `M-` で始まるもの) の組み合わせになる。dired などと違い、課題 (lessons) はまだない。

## クイックガイド

使い方を忘れたときは、この節を読めば org の全体がつかめるようにしている。

### キーの決め方

- evil のキーはそのまま使える (`j`・`k`・`gj`・`gk`・`gg`・`G` で動き、`/`・`n` で検索し、`i`・`a`・`o` で書く)。
  `gj`・`gk` は折り返した行の中を動く (evil の既定のまま)。
- org の操作は `C-c` か `M-` で始まる。normal state でも insert state でも同じように効く。
  `C-c` を押して少し待つと、続くキーの一覧が出る (which-key)。
- 自分の設定で変えたのは、normal state の `RET` (リンクを開く)・`C-h` (このガイド)・`M-h` (キーの一覧) の 3 つだけ。

### 見る・動く

- `TAB`: 見出しの上で、開く・閉じるを切り替える。`S-TAB`: ファイル全体を切り替える (概要 → 見出し → すべて)
- `SPC o`: 見出しの一覧から選んで飛ぶ (consult-outline)
- `C-c C-n` / `C-c C-p`: 次 / 前の見出しへ。`C-c C-f` / `C-c C-b`: 同じ階層の次 / 前の見出しへ。`C-c C-u`: 親の見出しへ
- `SPC /`: 中身を絞り込んで探す (consult-line)

### リンク

- `RET` (normal state): カーソルの上のリンクを開く (`[[file:…::*見出し]]` ならその見出しへ飛ぶ)。
  リンクの上でなければ、evil の `RET` と同じく次の行へ動く。`C-c C-o` でも開ける
- `C-o`: リンクを開く前の場所に戻る (evil の jump list)。`C-c &` でも戻れる
- `C-c C-l`: リンクを挿入する・カーソルの上のリンクを直す

### チェックボックス

- `C-c C-c`: `- [ ]` の行で、チェックを付ける・外す
- `M-S-RET`: チェックボックスの項目を、今の項目の下に足す (`M-RET` はチェックボックスなしの項目を足す)。
  insert state で押すと、そのまま続けて書ける

### 見出しやリストを組み替える

- `M-<left>` / `M-<right>`: 見出し・リストの項目を一段上げる / 下げる (`M-S-<left>` / `M-S-<right>` は子もいっしょに)
- `M-<up>` / `M-<down>`: 見出し (中身ごと)・リストの項目を、上 / 下と入れ替える
- `M-RET`: 次の見出し・リストの項目を足す (見出しの上なら見出し、リストの中なら項目)

### タグ

- `C-c C-q`: 見出しにタグを付ける・外す

### 困ったとき

- `C-h` (normal state): このクイックガイドを別のウィンドウに出す (`q` で閉じる)。insert state では backspace のまま
- `M-h`: 今のバッファで使えるキーをすべて一覧して、絞り込んで選ぶ (embark-bindings)
- `<f1> k` のあとにキー: そのキーが何をするかを見る
