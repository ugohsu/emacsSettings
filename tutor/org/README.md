# org

org-mode の操作のメモ。キーはこのリポジトリの `init.el` (evil + evil-org と自分の設定) を前提にしている。
evil-collection には org の設定がないので、org のキーは evil-org (https://github.com/Somelauw/evil-org-mode) と
org の標準のキー (`C-c` で始まるもの) で決まる。dired などと違い、課題 (lessons) はまだない。

## クイックガイド

使い方を忘れたときは、この節を読めば org の全体がつかめるようにしている。

### キーの決め方

- evil のキーはそのまま使える (`j`・`k`・`gg`・`G` で動き、`/`・`n` で検索し、`i`・`a` で書く)。
- evil-org が、見出しやリストに合わせて動くようにしたキーを足している (`o`・`<`・`>`・`gj` など。下の各節を参照)。
- org の操作の多くは `C-c` で始まる。normal state でも insert state でも同じように効く。
  `C-c` を押して少し待つと、続くキーの一覧が出る (which-key)。
- evil-org の `M-h`・`M-l` など (additional) は使っていない。`M-h` は今のバッファのキーの一覧 (embark-bindings) のまま。

### 見る・動く

- `TAB`: 見出しの上で、開く・閉じるを切り替える。`S-TAB`: ファイル全体を切り替える (概要 → 見出し → すべて)
- `SPC o`: 見出しの一覧から選んで飛ぶ (consult-outline)
- `gj` / `gk`: 同じ階層の次 / 前の要素へ (見出しの上なら次 / 前の見出し)。`gh`: 親の見出しへ。`gl`: 子へ。`gH`: 一番上の見出しへ
- `SPC /`: 中身を絞り込んで探す (consult-line)

### リンク

- `RET` (normal state) または `C-c C-o`: カーソルの上のリンクを開く (`[[file:…::*見出し]]` ならその見出しへ飛ぶ)
- `C-o`: リンクを開く前の場所に戻る (evil の jump list)。`C-c &` でも戻れる
- `C-c C-l`: リンクを挿入する・カーソルの上のリンクを直す

### チェックボックス

- `C-c C-c`: `- [ ]` の行で、チェックを付ける・外す
- `o` / `O`: リストの行で押すと、下 / 上に同じ形の項目を足して insert state に入る (チェックボックスの行なら `- [ ]` も付く)

### 見出しやリストを組み替える

- `>>` / `<<`: 見出し・リストの項目を一段下げる / 上げる (visual state で範囲を選んでから `>` / `<` でもよい)
- `M-<up>` / `M-<down>`: 見出し (中身ごと)・リストの項目を、上 / 下と入れ替える
- `C-RET`: 今の見出しの中身の後ろに、同じ階層の見出しを足す
- insert state の `C-t` / `C-d`: 見出し・リストの項目を一段下げる / 上げる (vim の `C-t` / `C-d` と同じ向き)
- insert state の `M-RET`: 次の見出し・リストの項目を足す

### 困ったとき

- `C-h` (normal state): このクイックガイドを別のウィンドウに出す (`q` で閉じる)。insert state では backspace のまま
- `M-h`: 今のバッファで使えるキーをすべて一覧して、絞り込んで選ぶ (embark-bindings)
- `<f1> k` のあとにキー: そのキーが何をするかを見る
