# レッスン 7: dired の `&` で裏で実行する (`07-dired-async`)

`&` は `!` の非同期版。裏で実行するので、終わるのを待たずに Emacs を使える。出力は `*Async Shell Command*` に出る。
`*`・`?` の使い方は `!` と同じ (レッスン 6)。複数のファイルがあるときの動き方は、コマンドの末尾で決まる。

| 入力 | 動き方 |
|---|---|
| `!` で `コマンド` | ファイルごとに 1 つずつ実行し、全部終わるまで Emacs が固まる |
| `&` で `コマンド` | 裏で、すべてのファイルを同時に (並列で) 実行する |
| `&` で `コマンド ;&` | 裏で、1 つずつ順番に実行する |

前のコマンドがまだ動いているときに `&` を使うと、別のバッファに出すか聞かれる。`y` で答えると、
`*Async Shell Command*<2>` のような別のバッファに出る。

## 並列と順番

- [ ] 右の dired で `07-dired-async` に入り、`job1.txt`・`job2.txt`・`job3.txt` に `m` で印を付ける。
      `!` で `sleep 2 && wc -c` と入力する。1 つずつ順番に実行するので、約 6 秒 Emacs が固まる。
- [ ] 印はそのまま、`&` で `sleep 2 && wc -c` と入力する。すぐに操作に戻れる (`j`・`k` で動いてみる)。
      約 2 秒後に、3 つの結果がまとめて `*Async Shell Command*` に出る (同時に実行したため)。
- [ ] 印はそのまま、`&` で `sleep 2 && wc -c ;&` と入力する。2 秒ごとに 1 つずつ結果が出る (順番に実行したため)。
- [ ] 印はそのまま、`&` で `mv * done/` と入力する。3 つのファイルが `done` に移る。
      大きなファイルを別のディスクに移すときなど、時間のかかる作業を裏に回すのに使う。

## 裏で動いているコマンドを見る・止める

裏で動いているコマンドは `M-x list-processes` で一覧できる (`*Process List*`)。`&` のほかに、
Emacs が起動したプロセス (vterm のシェルや eglot の言語サーバなど) も並ぶ。`&` のコマンドは、Process の列が `Shell` の行になる。

| キー | 動作 |
|---|---|
| `d` (`x`) | カーソル行のプロセスを止める (確認せずに止める) |
| `gr` | 一覧を作り直す (終わったプロセスが消える) |
| `q` | 一覧を閉じる |

- [ ] `done` の行で `&` を押し、`sleep 300 && ls` と入力する (5 分かかる)。`M-x list-processes` と入力すると、
      別のウィンドウに `*Process List*` が出る (カーソルは今のウィンドウに残る)。そのウィンドウに移り (`SPC h` など)、
      Command の列に `sleep 300` が見える行で `d` を押す。行が消え、エコーエリアに `killed` と出る
      (止めたので `ls` は動かず、結果も出ない)。`q` で一覧を閉じる。
      左に `00-tutor.md` が出ていなければ、左のウィンドウで `SPC b` から `00-tutor.md` を選んで戻す。
