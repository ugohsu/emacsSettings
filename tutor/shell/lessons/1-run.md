# レッスン 1: `:!` でコマンドを実行する (`1-run`)

`:!コマンド` は、シェルでコマンドを 1 回実行して出力を見る (バッファは変わらない)。
作業ディレクトリは、今のバッファのファイルがあるディレクトリになる。

| 入力 | 動作 |
|---|---|
| `:!コマンド` | 実行して出力を見る (短ければエコーエリア、長ければ `*Shell Command Output*`) |
| `:!!` | 直前のコマンドをもう一度実行する |
| `:` のあと `C-p` / `C-n` | 履歴をさかのぼる / 戻る |
| `TAB` | コマンド名・ファイル名を補完する |
| `:` のあと `C-f` (normal state から `q:` でも) | 履歴をバッファに並べて、evil の操作で直す (コマンドラインウィンドウ) |
| (その中で) `RET` / `C-c` | カーソル行をすぐに実行する / カーソル行を `:` に戻す (自分の設定。戻ったあと `TAB` で補完できる) |
| `%` | 今のファイルの絶対パスに置き換わる (`%` そのものを渡すときは `\%`) |
| `:!コマンド &` | 裏で実行する (Emacs は固まらない。出力は `*Async Shell Command*`) |

- [ ] 右の dired で `1-run` に入り、`notes.txt` を開く。`:!ls` と入力すると、エコーエリアにファイルの一覧が出る。
- [ ] `:!ls -l /usr/bin` と入力する。長いので `*Shell Command Output*` が別のウィンドウに出る。
      左の `00-tutor.md` と入れ替わったら、`SPC h` で左に移って `SPC b` から `00-tutor.md` を選んで戻す。
- [ ] `:!bash greet.sh 太郎` と入力する (`こんにちは、太郎さん` と出る)。`notes.txt` と同じディレクトリで動くので、パスを書かなくてよい。
- [ ] `:!!` と入力すると、同じコマンドがもう一度動く。
      次に `:` を押してから `C-p` で履歴をさかのぼり、`太郎` を `花子` に書き換えて実行する。
- [ ] `:!wc -l %` と入力する。`%` が `notes.txt` の絶対パスに置き換わって、行数が出る。
- [ ] パイプもそのまま使える。`:!grep ERROR logs/app.log | wc -l` でエラーの行数を数える。
- [ ] bash の文法も使える。`:!echo {1..5}` と、`:!for f in *.txt; do echo "== $f"; head -1 "$f"; done` を試す。
- [ ] `%` の落とし穴: `:!date +%H:%M` と入力すると、`%` がファイル名に置き換わって変な出力になる。
      `:!date +\%H:\%M` と書き直すと、時刻が出る。
- [ ] 補完: `:!cat no` まで入力して `TAB` を押すと、`notes.txt` が補完される。`:!ech` で `TAB` を押すとコマンド名 `echo` が補完される。
      `C-g` で入力をやめる。
- [ ] 裏で実行: `:!sleep 3 && echo おわり &` と入力すると、すぐに操作に戻れる。
      3 秒後に `*Async Shell Command*` に `おわり` と出る。

vim と違い、`:!python3` のような対話するコマンドは使えない (入力が渡らないので、何もせずに終わる)。
対話するときは `SPC :` で vterm (ターミナル) を開く (レッスン 8)。

## 履歴を evil の操作で直す (コマンドラインウィンドウ)

`:` の中で `C-f` を押すと、`:` の履歴が普通のバッファ (`*Command Line*`) に 1 行ずつ並ぶ (古いものが上、一番下が今の入力)。
normal state で開くので、`j`・`k` で行を選び、`cw`・`ciW`・`$`・`.` など evil の操作でそのまま直せる
(`C-p` で 1 つずつさかのぼって矢印キーで直すより速い)。直した行は、`RET` ですぐに実行するか、`C-c` で `:` に戻す。

- `RET`: カーソル行をそのまま実行する。
- `C-c`: カーソル行を持って `:` に戻る (vim と同じキー。evil にはないので自分の設定で足している)。
  このバッファの中では補完が効かないので、補完したいときは `C-c` で戻ってから `TAB` を押す。
- 何もせずにやめるときは、`SPC 0` でウィンドウを閉じる (`:` に戻るので、続けて `ESC` か `C-g`)。

- [ ] `:` を押してから `C-f` を押す。下にウィンドウが開き、ここまでに入力したコマンドが並んでいる。カーソルは一番下の空の行にある。
- [ ] `k` で `!bash greet.sh 花子` の行に移り、`$` で行末に行って `ciW` で `次郎` と書き換え、`ESC` → `RET` で実行する
      (`こんにちは、次郎さん` と出る)。
- [ ] もう一度 `:` → `C-f` で開き、`!wc -l %` の行に移る。`$` → `ciW` で `no` と書き換え、`ESC` を押さずに `C-c` を押す
      (insert state のままでも効く)。`:` に `!wc -l no` が入った状態に戻るので、`TAB` で `notes.txt` まで補完して `RET` で実行する。
- [ ] normal state で `q:` と押しても、同じウィンドウが開く。`:!!` の行を選んで `C-c` を押すと、その行が入った `:` が開く。
      `C-g` でやめる。
