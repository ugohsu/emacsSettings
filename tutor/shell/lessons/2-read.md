# レッスン 2: `:r !` で出力を取り込む (`2-read`)

`:r !コマンド` は、コマンドの出力をカーソル行の下に挿入する。挿入したあと、カーソルは挿入した最後の行に移る。
`!` を付けずに `:r ファイル名` と書くと、ファイルの中身を挿入する。

| 入力 | 動作 |
|---|---|
| `:r !コマンド` | 出力をカーソル行の下に挿入する |
| `:r ファイル名` | ファイルの中身をカーソル行の下に挿入する |
| `u` | 挿入を取り消す |

- [ ] 右の dired で `2-read` に入り、`report.md` を開く。`日付:` の行で `:r !date +\%F` と入力する。
      次の行に今日の日付が入る。`k` で `日付:` の行に戻り、`J` で 1 行にまとめる。
- [ ] `## ファイル一覧` の行で `:r !ls` と入力する。このディレクトリのファイル名が並ぶ。
- [ ] `u` で取り消して、`:r !ls | sed 's/^/- /'` と入力する。今度は markdown の箇条書きになる。
- [ ] `## 課題` の行で `:r !printf -- '- [ ] 課題 \%s\n' {1..3}` と入力する。チェックボックスが 3 つ入る
      (`printf` の `%s` も `\%s` と書く)。
- [ ] `## 定型文` の行で `:r template.md` と入力する。`template.md` の中身が入る。

ここで書き換えた `report.md` は保存しなくてよい。
