# レッスン 3: `!` で行をコマンドに通して置き換える (`3-filter`)

範囲の行をコマンドの標準入力に渡し、**出力で置き換える** (vim のフィルタと同じ)。
ノーマル状態で `!` に続けて範囲 (モーション) を押すと、範囲が入った状態でコマンドラインが開くので、コマンドを入力する。

| 入力 | 範囲 |
|---|---|
| `:%!コマンド` | バッファ全体 |
| `!!` | 今の行 (コマンドラインに `:.!` が入る) |
| `3!!` | 今の行から 3 行 |
| `!ip` | 今の段落 (空行で区切られたまとまり) |
| `!G` | 今の行から最後の行まで |
| `V` で選んで `!` | 選んだ行 (コマンドラインに `:'<,'>!` が入る) |
| `u` | 置き換えを取り消す |

コマンドが失敗すると、範囲がエラーメッセージに置き換わる。そのときは `u` で戻す。

- [ ] 右の dired で `3-filter` に入り、`members.txt` を開く。1 行目で `!ip` を押し、`sort` と入力する。
      最初の段落 (空行の前の 4 行) だけが並べ替わる。
- [ ] `u` で戻して、もう一度 `!ip` で `sort -u` と入力する。並べ替えたうえで、2 つあった `suzuki` が 1 つになる。
- [ ] `:%!sort` と入力すると、バッファ全体が並べ替わる (空行が先頭に集まる)。`u` で戻す。
- [ ] `yamada` の行で `!!` を押し、`tr a-z A-Z` と入力する。その行だけが大文字になる。
- [ ] `u` で戻して、`yamada` の行で `3!!` を押し、同じく `tr a-z A-Z` と入力する。3 行とも大文字になる。
- [ ] 1 行目で `V` を押して `j` で 2 行選び、`!` を押して `sort -r` と入力する。選んだ 2 行だけが逆順に並ぶ。
- [ ] 1 行目で `!G` を押し、`cat -n` と入力する。最後の行まで、行番号が付く。`u` で戻す。
- [ ] 失敗したとき: `:%!sortt` と入力すると、全体が `command not found` のメッセージに置き換わる。`u` で戻す。
- [ ] `numbers.txt` を開き、`:%!sort` と入力する (`10` が `2` より前に来る。文字として並べるため)。
      `u` で戻して `:%!sort -n` と入力すると、数の大きさの順に並ぶ。
