# レッスン 4: よく使うフィルタ (`4-filter-more`)

レッスン 3 の `!` (`:%!`・`:範囲!`) に、よく使うコマンドを組み合わせる。範囲は `:2,$` (2 行目から最後まで) のように行番号でも書ける。

| コマンド | すること |
|---|---|
| `column -t` | 空白区切りの列をそろえる |
| `sort -t, -k2 -nr` | `,` 区切りの 2 列目で、数の大きい順に並べる |
| `awk -F, '条件'` | `,` 区切りで、条件に合う行だけ残す |
| `cut -d, -f1` | `,` 区切りの 1 列目だけ残す |
| `sort \| uniq -c \| sort -nr` | 同じ行を数えて、多い順に並べる |
| `sed 's/^/- /'` | 行の頭に文字を足す |
| `nl -w1 -s'. '` | 行の頭に `1. ` などの番号を付ける |

- [ ] 右の dired で `4-filter-more` に入り、`table.txt` を開く。`:%!column -t` と入力すると、列がそろう。
- [ ] `scores.csv` を開き、`:2,$!sort -t, -k2 -nr` と入力する。見出しの行を残して、点数の高い順に並ぶ。
- [ ] `u` で戻して、`:2,$!awk -F, '$2 >= 70'` と入力する。70 点以上の行だけが残る。`u` で戻す。
- [ ] `:%!cut -d, -f1` と入力すると、名前の列だけが残る。`u` で戻す。
- [ ] `words.txt` を開き、`:%!sort | uniq -c | sort -nr` と入力する。単語ごとの回数が、多い順に並ぶ。
- [ ] `list.md` を開き、`:%!sed 's/^/- [ ] /'` と入力する。チェックボックスの箇条書きになる。
      `u` で戻して `:%!nl -w1 -s'. '` と入力すると、番号付きの箇条書きになる。
