# レッスン 5: `:w !` で行をコマンドに渡す (`5-write`)

`:w !コマンド` は、範囲の行をコマンドの標準入力に渡して、出力を見る (`:!` と同じところに出る)。
`!` (レッスン 3) と違い、**バッファは置き換えない**。書いたコードや、メモに書いたコマンドを、その場で動かすのに使う。

| 入力 | 範囲 |
|---|---|
| `:w !コマンド` | バッファ全体 |
| `:.w !コマンド` | 今の行 |
| `V` で選んで `:` → `w !コマンド` | 選んだ行 (`:` を押すと `:'<,'>` が入る) |

`:w !python3` と `:w! python3` は別物 (vim と同じ)。空白が `!` の後ろにあると、
`python3` という名前のファイルにバッファを書き出してしまう。

- [ ] 右の dired で `5-write` に入り、`calc.py` を開く。`:w !python3` と入力すると、
      `[1, 2, 3]`・`6`・`3.14…` が出る。バッファはそのまま。
- [ ] 1 行目で `V` を押して `j` で 2 行選び、`:` を押す。`:'<,'>` に続けて `w !python3` と入力すると、`[1, 2, 3]` だけが出る。
- [ ] 比べてみる: `:%!python3` と入力すると、バッファが出力で置き換わってしまう。`u` で戻す。
- [ ] `commands.md` を開き、`ls -l` の行で `:.w !bash` と入力する。その行のコマンドが動く。
      `j` で `du -sh .` の行に移って、`:` → `C-p` で同じ入力を呼び出して実行する。
- [ ] `essay.txt` を開き、`:w !wc -m` と入力する。文字数 (改行も含む) が出る。
