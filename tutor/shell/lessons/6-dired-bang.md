# レッスン 6: dired の `!` と `*`・`?` (`6-dired-bang`)

dired で `!` を押すと、印の付いたファイル (印がなければカーソル行のファイル) にシェルコマンドを実行する。
作業ディレクトリは dired のディレクトリ。コマンドの中の `*` と `?` (前後に空白があるとき) で、ファイル名の入り方が変わる。

印の付いたファイルが `a b.txt` と `c.txt` のとき、実際に動くコマンドとシェルでの近い書き方:

| 入力 | 動き方 | 実際に動くコマンド | シェルでいうと |
|---|---|---|---|
| `wc -l` (どちらもなし) | ファイルごとに、名前を末尾に付けて実行 | `wc -l a\ b.txt; wc -l c.txt` | `xargs -n1 wc -l` |
| `wc -l *` | 1 回だけ、`*` の位置に全部入れて実行 | `wc -l a\ b.txt c.txt` | `xargs wc -l` |
| `cp ? backup/` | ファイルごとに、`?` の位置に名前を入れて実行 | `cp a\ b.txt backup/; cp c.txt backup/` | `xargs -I{} cp {} backup/` |
| `` cp ? backup/`?`.orig `` | `` `?` `` なら単語の途中にも入れられる | `cp a\ b.txt backup/a\ b.txt.orig; …` | `xargs -I{} cp {} backup/{}.orig` |

- `*` はシェルのワイルドカードではなく、**印の付いたファイルの一覧**に置き換わる。印がなければ、カーソル行のファイル 1 つだけになる。
- ファイル名は自動でクォートされるので、空白の入った名前でも安全 (`:!` の `%` はクォートされない)。
- `*` と `?` が特別なのは、前後が空白のとき (`?` は `` `?` `` と書いたときも)。`?.bak` のように単語にくっついていると置き換わらず、確認を求められる。
- 本当にシェルのワイルドカードとして `*` を使いたいときは、`*""` と書く。
- `*` と `?` は、1 つのコマンドの中で一緒には使えない。
- 実行後、少し待つと一覧が自動で更新される。すぐに見たいときは `gr` を押す。

- [ ] 右の dired で `6-dired-bang` に入る。印を付けずに `c.txt` の行で `!` を押す。
      プロンプトに `c.txt` と出るので、`wc -l` と入力する (`2 c.txt` と出る)。
- [ ] `a b.txt`・`c.txt`・`d.txt` に `m` で印を付け、`!` で `wc -l` と入力する。ファイルごとに 3 回実行される (合計の行はない)。
- [ ] 印はそのまま、`!` で `wc -l *` と入力する。1 回の実行で 3 つまとめて数えるので、最後に合計 (`total`) の行が付く。
- [ ] 印はそのまま、`!` で `cp ? backup/` と入力する。`backup` に `l` で入ると 3 つコピーされている。`h` で戻る。
- [ ] 印はそのまま、`!` で `` cp ? backup/`?`.orig `` と入力する。`backup` に `.orig` の付いたコピーができる。
- [ ] 印はそのまま、`!` で `mv ? ?.bak` と入力する。2 つ目の `?` は単語にくっついているので、確認を求められる。`n` で答えてやめる。
- [ ] `U` で印を全部外す。`d.txt` にだけ印を付けて、`!` で `rm *` と入力する。消えるのは `d.txt` だけで、ほかのファイルは残る
      (`*` は印の付いたファイルに置き換わるため)。ふだん消すときは `D` を使う。

`!` は、終わるまで Emacs が固まる。時間のかかるコマンドは `&` (レッスン 7) で実行する。
