# レッスン 8: evil の外で使う・使い分け (`8-other`)

evil の `:` が使えないところ (insert state の途中や、evil の効かないバッファ) では、Emacs 標準のキーを使う。
どれも `%` の置き換えはないので、`date +%F` のように `%` をそのまま書ける。

| キー | 動作 | evil でいうと |
|---|---|---|
| `M-!` | シェルコマンドを実行して出力を見る | `:!` |
| `C-u M-!` | 出力をカーソル位置に挿入する | `:r !` |
| `M-&` | 裏で実行する | `:!コマンド &` |
| `M-\|` | 選んだ範囲 (リージョン) をコマンドに渡して出力を見る | `:'<,'>w !` |
| `C-u M-\|` | 選んだ範囲を出力で置き換える | `V` で選んで `!` |

`M-|` は、evil が効かず `V` で選べないところで使う。そこでは範囲を Emacs 標準の `C-SPC` (選び始め) と移動キーで選ぶ。
`V` で選べるときは、vim と同じく `!` (レッスン 3) か `:'<,'>w !` (レッスン 5) を使う。
ここでは `C-z` で evil を止めた状態 (emacs state。モードラインに `<E>` と出る) にして練習する。もう一度 `C-z` で normal state に戻る。

- [ ] 右の dired で `8-other` に入り、`memo.txt` を開く。`M-!` で `ls` と入力する (`:!ls` と同じ)。
- [ ] `今日は` の行の末尾で `A` を押して insert state にし、`C-u M-!` で `date +%F` と入力する。カーソル位置に日付が入る。`ESC` で戻る。
- [ ] `りんご` の行の先頭 (`j` で移って `0`) で `C-z` を押し、emacs state にする。`C-SPC` を押してから `C-n` を 3 回押して果物の 3 行を選び、
      `M-|` で `wc -l` と入力する (`3` と出る。バッファはそのまま)。
- [ ] `C-g` で選択を外し、`C-p` を 3 回押して `りんご` の行の先頭に戻る。同じように 3 行を選び、`C-u M-|` で `sort` と入力する。
      選んだ行が並べ替わる。`C-/` で戻し、`C-z` で normal state に戻る。
- [ ] 対話するコマンド: `:!python3` と入力しても、何も起きずに終わる (入力が渡らないため)。
      `SPC :` で eat (ターミナル) を開き、`python3` と入力すると対話できる。`exit()` で抜け、`exit` でシェルを終える (eat のバッファとウィンドウは残るので、`SPC 0` でウィンドウを閉じる)。

## どれを使うか

| したいこと | 使うもの |
|---|---|
| 結果を見るだけ | `:!` |
| 結果をバッファに入れる | `:r !` |
| 行を加工して置き換える | `!` (`:%!`・`!!`・`!ip`・`V` で選んで `!`) |
| 行をコマンドに渡して結果を見る (置き換えない) | `:w !` |
| ファイルを対象に実行する | dired の `!` (時間がかかるなら `&`) |
| evil の `:` が使えないところ | `M-!`・`M-&`・`M-\|` |
| 対話するコマンド・長い作業 | `SPC :` (eat) |
